# 固定插件源

当前插件来自独立公开仓库 [JieWaZi/neux-plugins](https://github.com/JieWaZi/neux-plugins)。应用默认通过 HTTP Release 的 `catalog.json` 读取目录，按目录指定地址和 SHA-256 获取安装 ZIP；运行期间不调用 Git。目录元数据与安装归档由插件仓库构建发布，应用不内置插件安装包。测试发布固定覆盖 `v0.1.0` 时仍逐次校验摘要，不把同名 URL 当作不可变内容。

`pnpm plugins:prepare` 只生成软件来源元数据并为旧版已安装资源准备固定 CLI 资产；不从历史 bundle 构建插件 ZIP，也不生成覆盖上游 README 的阅读指南。`pnpm plugins:check` 校验来源声明与本地资产规则。`ALLY_PLUGIN_CATALOG_URL` 可明确选择 HTTP 镜像或本地目录；默认不会因旧资源目录仍有 `catalog.json` 而回退旧目录。

本目录的历史 bundle、来源锁和许可材料保留旧版包的来源证据与已安装资源兼容所需的依赖来源，不是新目录的运行权威。插件的原生来源、授权桥接、依赖下载锁和发布流程以独立仓库为准；应用负责完整快照、来源选择和通用授权会话。

独立仓库只维护 `plugins/<name>/` 下的一套 OpenAI/Codex 标准内容，按许可复用官方开源能力并保留来源与修改记录；不再分别维护 Codex 和 Claude 两套收录。GitHub 包含官方远程 MCP 和自己的通用授权桥接，飞书包含官方技能与桥接。插件程序依赖在独立仓库构建并按摘要分发，不沿用下述既有提供者包装作为新插件接入方式。NeuxBot 只安装此自有插件库条目，不支持上传、目录或 ZIP 导入。内部 adapter 负责把受维护的同一标准内容交付为对应 CLI 的原生格式。聊天安装的第三方原生插件与外部相同 CLI 共用原生环境，不在系统展示和管理。

## 既有来源与程序资产

飞书包保留官方固定提交的完整 `skills/` 与相对引用、许可证和 provenance；首版主验收路径为文档、多维表格、日程和任务。包维护者与上游作者分别记录。原生程序只进入构建产物，不提交大型程序文件，也不安装到全局 PATH。

GitHub 包使用官方远程 MCP 及固定 GitHub CLI 2.102.0 的隔离构建（2.102.0-neuxally.1）。源码归档、Go 1.27.1 工具链及 patches/ 中底层钥匙串命名空间补丁固定；构建会运行上游真实登录编排的隔离回归。原始发布程序即使使用 --insecure-storage 仍会访问其他 gh 钥匙串，因此不能直接作为本应用的登录程序。离线构建还需预先缓存该工具链和 go.sum 固定的模块依赖。开发者标注为 GitHub，清单包含官方源码、隐私政策与服务条款链接；包装与认证适配由 NeuxBot contributors 维护，操作能力来自官方 MCP；MCP 是远端服务，不随本地包复制或固定服务实现版本。两个提供者程序和许可证均按目标平台进入构建产物。
