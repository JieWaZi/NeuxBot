# 资源目录与详情 UI 标准

本文是插件、技能、连接器目录、详情和添加页的视觉权威；工作流仅在资源目录及导航归属上适用。全局基础、焦点和可访问性要求见 [UI 标准](ui-cn.md)，领域事实见[插件资源](../architecture/plugin-resources-cn.md)。

## 1. 设计依据与判定顺序

资源界面以本项目领域所有权、共享组件和语义 Token 为依据。组件映射表示职责归属，不代表所有状态已完成真实视觉验收。

样式核对顺序为实际调用的 `variant`／`size` → 基础样式 → 宿主上下文 → 当前主题 Token → 布局和交互状态。资源目录、详情和表单分别使用自己的共享变体，不从单个类名或截图估算尺寸。

本规范的资源角色优先于普通控件默认；主题、键盘焦点、数据与执行所有权遵守全局约束。共享层缺少能力时在共享层补齐，不在业务页面覆盖基础控件。

## 2. 组件角色与操作矩阵

先确定动作归属，再选择共享变体。资源目录、详情和表单分别维护密度；基础尺寸不在业务页面覆写。

| 角色           | 本项目组件与约束                                                   |
| -------------- | ------------------------------------------------------------------ |
| 身份头下一步   | 安装使用主动作，复制链接与伙伴安装使用轮廓动作；只显示真实可用操作 |
| 分区标题操作   | 与标题同一行，操作只影响所属分区；无动作不预留按钮                 |
| 详情行操作     | 内容、媒体与动作分槽，局部操作不触发整行导航                       |
| 危险操作       | 使用危险 ghost 变体，文字常驻危险语义色；删除或卸载前确认影响      |
| 浏览行尾操作   | 与整行导航独立命中，已安装文字状态不伪装可点击按钮                 |
| 图标操作       | 复用共享图标按钮，提供 Tooltip、可访问名称和至少 36px 的独立命中区 |
| 信息链接       | 自然高度、零额外内边距，显示具体目标或仓库名                       |
| 表单重置与保存 | 使用所属 pane 的 footer；表达未保存、错误与提交状态，阻止重复提交  |

资源文字按钮使用 `catalog`／`catalog-form` 变体，高 32px、水平内边距 12px、间隔 6px、字号 14px、字重 500；表单文字为 14/20。按钮与图标的具体值由共享层维护。`catalog`、`catalog-form` 和 `catalog-icon` 使用 `radius-control`，40px 的 `catalog-icon-lg` 使用 `radius-xl`；圆形和胶囊只在明确变体使用。

轮廓动作、主动作、次级动作和 ghost 动作各自使用语义表面；危险、禁用、忙碌与键盘焦点分别表达。普通 Card 不增加装饰外框或阴影，结构分隔、字段边界和状态轮廓保留各自职责。

| 内容角色 | 排版与交互                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 浏览行   | 8px 内边距、12px gap、12px 圆角、40px 媒体槽；名称 14/21、说明 13/19.5，各一行截断；整行导航和尾部动作分离 |
| 详情行   | 最小高 64px、12px 16px 内边距、16px gap；行本身无额外边框，相邻行使用内缩分隔线                            |
| 信息区   | 说明正文与真实字段处于同一 Card；字段标签和值分别排版，长值可缩小或换行                                    |
| 分区     | 标题、必要说明及局部动作在同一标题行，内容使用单张填充 Card；分区不重复套外框                              |

## 3. 页面 Shell 与内容结构

资源目录使用左栏分类和可缩小的正文滚动区。列表与详情共享最大 880px 内容宽度，正文上 40px、下 32px、横 24px 留白，窄容器横向 16px。左栏与正文独立滚动，统一分隔规则见 [Shell 布局](ui-cn.md#工作台与可访问性)。

目录标题为 24/24、字重 600。搜索与相邻添加或 Info 入口处于同一工具行，不增加重复计数、批量工具栏或页签。分类页保留父级路径和分类内搜索。浏览列表每列至少 320px、列距 24px、行距 4px，最多两列，实际空间不足时单列。

左栏只在具有真实安装数据时展示已安装快捷组；不能以搜索结果或首批数据推导完整数量。当前资源使用 `aria-current=page`，所属分类使用 `aria-current=location`。

详情顺序为身份头、读取错误或领域提醒、试用、领域内容、信息、危险区；只有真实可移除时才显示末尾危险区。伙伴安装、技能正文、连接器工具分别使用已有领域入口。

身份头图标槽为 48px、12px 圆角，品牌图片保持比例并居中占槽的 75%。名称 16/22、字重 600，简介 12/16、单行截断并可悬停阅读。状态标签使用共享组件及真实状态，不根据文字猜测颜色或可用性。

## 4. 滚动、表单与保存条

添加页保留所属资源 Scene，复用共享身份头、字段和返回行为。表单填满所属列；标签可见，placeholder 提供示例，必要格式、权限和信任说明保留，错误就近显示。

资源表单使用独立共享变体：输入框高 32px、文字 14/20；说明文本域最小高 76px，可纵向调整。搜索框使用共享复合结构，不重复嵌套边界或横向内边距。名称、地址、环境变量、请求头等由共享字段维护外观。

来源和传输切换使用 SegmentedControl 的 `catalog-form` 外观：轨道高 34px、选项高 28px、轨道与选项圆角分别为 8px 和 6px；按内容自然宽度排列，空间不足时换行。伙伴／团队切换使用自身 shell 变体，不合并两种角色。

技能编辑与连接器表单共用 `ResourcePageFooter`。保存条挂所属 pane 底部槽，与正文滚动区平级；跨 Portal 提交关联原表单。条体最小高 60px，内边距对齐正文；短表单贴底，长表单只滚动正文，最后字段不被遮挡。未修改时不保留永久确认条，有修改后提供重置和提交；失败保留草稿，提交中阻止互斥操作。

## 5. 主题、焦点与状态

颜色、排版、圆角、表面与状态由 `shared/styles` 和 `shared/ui` 管理。浅暗主题使用相同结构和尺寸，不在业务页面复制固定色值。画布、填充 Card、字段、悬停表面及抬升浮层各自保留语义。

键盘焦点使用 `focus-visible` 与共享语义 Token；鼠标点击、拖动或程序化导航不为整块滚动区、画布或页面增加外框。禁止浏览器默认黄橙轮廓。返回、关闭弹层和失败重试保留合理焦点位置。

首次读取使用与内容匹配的 Skeleton，Shell、页头、返回、搜索和 Tab 保持挂载。无数据、无搜索结果、后台刷新、陈旧、失败和禁用分别表达；后台刷新保留旧数据，不伪造资源、计数、伙伴或授权。

共享试用卡保留网格渐变、资源引用与圆形箭头：卡片最小高 160px、20px 圆角、24px 内边距，请求行最大宽 560px、行高 24px，箭头 40px。CSS 与 Shader 读取同一 artwork Token，离屏、隐藏及减少动态效果时释放动画并保留静态渐变。

## 6. 本产品能力扩展与业务约束

### 目录与导航

- 插件通过标准 category 分组，空组隐藏，未知分类归其他，不按名称推测；公开窄摘要每批至多 100 项，完整读取成功后才能发布完整目录数量，失败或取消不把部分数据当全集。
- 技能库仅含 GitHub 同步、ZIP 上传的独立技能；插件技能从所属插件进入，不重复出现在技能库。用户自设分类使用可输入的多选标签字段，外层统一绘制字段边界，内层输入不重复焦点轮廓或环；输入过滤已有项，回车或点击新建；草稿只在保存所属表单时写入，同类型资源共享选项。多个分类分别参与技能分组，空数组为“未分类”，每组预览六项，分类页每批 24 项；插件与技能滚动接近底部自动追加，不显示“加载更多”。分类与分类内搜索保存于 URL，不伪造 Verified、Public、推荐或安装量。
- 连接器轻量列表仅展示独立资源；插件 MCP 从所属插件进入固定来源详情，不重复展示到独立连接器列表，不保留旧来源分组、来源／启用筛选、批量选择、总数工具条或伙伴数第三行；尾部仅保留真实安装或当前伙伴启停，无真实分类时不编造分组。内置资源遵守实际维护限制。
- 技能、MCP、工作流及缺少品牌图的插件共用十组分类颜色和 Lucide 图标；图标与配色采用本产品选择，不复刻参考图。常见分类使用固定对应，自设分类按规范化名称稳定映射并复用预留组合，不随列表顺序、搜索或刷新变化。多分类资源在各分组使用该组标识；未分组的条目与详情使用首个分类。所有未分类条目统一使用同一底色与积木图标，不按资源名称或身份分别选槽。颜色由浅／暗主题语义 Token 提供，插件已有品牌图片保持真实来源。
- 工作流作为全局资源库分类，与插件、技能、连接器共用 catalog 左栏、页头、整行搜索与两列轻量条目，创建入口紧邻搜索；条目展示名称与说明，尾部更多菜单提供详情和经确认的删除动作，与整行导航独立命中；不保留总数工具栏或版本底栏，不推导安装状态。工作流多选分类复用共享分类表和标签字段，在基本信息弹窗保存，分类修改不产生源码版本；列表按真实标签分组并提供分类筛选，筛选和搜索保存在 URL，服务端在游标分页前过滤，每批 24 项并滚动追加，不把已加载条目数当完整分类数量。进入新建、详情或运行页后隐藏整个资源分类侧栏，画布与创作对话使用完整主容器，模块栏仍选中资源库；版本、运行及编辑操作留在画布内，返回资源列表保留原搜索和分类条件。
- 添加技能／连接器进入同一资源 Scene，入口、面包屑和可见页标题使用对应的“添加…”；复用共享身份头的返回行为，不增加第二个返回箭头，返回校验并保留原分类、搜索及伙伴上下文。

### 插件与技能详情

- 插件真实安装伙伴紧随有数据的 TryCard，位于连接、组件、信息之前；伙伴页只显示自身固定版本。共享配置与账号进入已有管理入口，本地化连接说明留在连接 Card。
- 插件详情请求失败时由共享查询状态在所属内容区展示错误和重试入口。
- 技能详情保留 SKILL.md／资源文件／版本三个可切换入口，使用既有 shell、sm、fill SegmentedControl；数据未就绪仍保持挂载，保留 URL、草稿、真实文件、历史及差异能力。三个入口共享同一详情身份与草稿生命周期。
- 独立技能名称与分类在身份头的同一编辑表单一次保存；分类移除全部标签时清空，不改正文或生成版本，信息区只读。全局删除移除全部版本和实际安装关系；伙伴“移除”仅断开当前关系。详情读取完整实际伙伴，不把最多四头像摘要当完整关系。
- 插件技能及 MCP 从所属入口进入固定来源只读详情，保留版本、目录提交、归档摘要和伙伴上下文；不提供组件独立编辑、删除、启停或更新。信息区展示真实来源链接，不额外在页头加“查看插件”。
- 技能文档使用有边界阅读表面与 16px 24px 内边距、12px 正文；本项目 Markdown 标题变体为 h1 20/24、h2 16/22、h3–h6 14/20。“查看完整内容”归所属分区标题右侧。信息只展示真实字段，作者能力声明不作为常驻信息，仓库链接显示具体拥有者／仓库，不以托管域名冒充作者。

### 连接器详情与试用

- 本产品连接器详情顺序为身份头 → 共享 TryCard → 当前伙伴操作 → 工具 → 信息 → 底部危险区。试用、工具诊断和信息各自展示真实领域数据。
- 当前伙伴启停及共享资源移除放在伙伴行；全局删除和伙伴自有资源删除在危险区明确实际影响并确认。全局只展示接口提供的真实计数，不据计数推导伙伴名单。
- 工具名与说明各一行，超出截断并可悬停阅读，不限定说明的固定字符宽度。显式测试与诊断 Info 在工具标题行，状态、时间与耗时在可交互浮层；失败就近保留。页面不展示 CLI 兼容阵列，后台传输兼容校验保留。普通读取不探测、不授权；固定目录预览未匹配真实本地版本时不伪造可测试状态。
- 插件优先使用当前语言的非空作者 defaultPrompt，其次使用默认作者示例，均缺少时使用本地化产品 fallback“帮我使用这个插件。”；技能使用真实示例或 fallback“帮我使用这个技能。”；连接器使用本产品 fallback“帮我使用这个连接器。”。产品默认提示不冒充作者示例。
- 试用只创建独立聊天草稿：独立技能用 skill 引用，独立连接器用 connector 引用，插件技能与 MCP 用所属插件引用；不复制 SKILL.md、工具清单、命令或配置，不自动安装、启用、授权、测试或发送。
- 当前或所选伙伴须有实际已启用关系，技能及插件须与预览固定版本一致；目录预览须先核验本地安装身份与来源摘要。全局入口先选伙伴；未安装、停用、系统场景或身份未核验时保留卡片并禁用箭头，或在选择区就近解释，原因通过可访问描述提供。
- 普通聊天的连接器可选性与 Try 复用同一策略规范化，不以旧连接测试成功／失败快照判断能否建立草稿。输入区等待真实可选资料后一次性写入既有 Mention；后续刷新或用户删除不重复插入。

### 添加能力

- 添加技能的 GitHub／ZIP 来源切换和添加连接器的传输切换，放在共享 PageHeader 的标题右侧 actions 槽；这是本产品页面布局要求。`compact + form` 身份区按标题自然宽度增长，动作保持自然宽，只有实际容纳不足才换行，不用固定 basis 提前拆行。来源切换仍由唯一表单状态持有；扫描、上传、提交及已入库待安装状态保持原有禁用和清理语义。
- 添加技能使用 GitHub／ZIP 两个来源；默认将所选技能加入统一技能库，伙伴入口随后显式安装。未入库且选中至少两个技能时，在主添加动作之前提供次级“添加为插件”；在同页填写插件名称与可选说明，核对所选技能，不新开命名弹窗。取消命名保留扫描批次、勾选及草稿，失败就近重试。创建只使用所选候选生成 skills-only 插件，不重复导入独立技能，也不提供公开／私有或自动发布操作；全局创建后进入真实插件详情并可返回插件库，伙伴入口继续复用已有插件安装确认。安装失败或取消保留已创建插件，重试安装不重复创建。普通独立技能安装失败同样保留已入库资源和安装重试，不重复导入或自动删除。
- ZIP 使用共享 FileDropZone 点击或拖入，业务层校验格式、传输大小和暂存；本地路径扫描保留，浏览器传输与解压批量预算分别表达。“识别到的技能”区始终保留 Card 和标题，未扫描、扫描中、空结果、失败使用对应占位；成功展示真实候选与重复资源信息。
- 连接器添加保留 STDIO、Streamable HTTP、SSE、环境变量、请求头和信任确认；新建不展示超时字段，使用既有默认 10 秒。编辑与详情的启动／测试超时使用秒，范围 0.1–300 秒、保留三位小数精度；表单只持有秒值，在 API 边界与整数毫秒转换，历史毫秒值不因编辑其他字段被取整。环境变量／请求头的“添加”属于字段局部 outline 动作。全局创建仅入库，伙伴入口仍创建自身连接器并安装启用，布局变化不改资源所有权。

## 8. 验收检查

- 按本规范分别检查基础组件、实际宿主选择器、主题 Token 和最终盒模型；记录 computed 值时同时记录资源类型、上下文和状态。
- 检查身份头、分区、详情行、浏览行、危险区、信息链接和保存条的按钮角色；尺寸相近不能代替 border、文字层级、图标 stroke、hover 和 disabled 一致。
- 浅／暗主题、宽／窄 Scene、长中文、空列表、加载、失败、停用、身份未知均可读；整行导航和尾部动作互不误触，图标按钮可用键盘并有名称。
- 短表单保存条贴 pane 底；长表单仅正文滚动且最后字段不被遮；分屏、窄窗口和错误换行后仍可重置、提交、恢复焦点。
- 添加页标题与自然宽切换在 400px 内容区及更窄容器按实际空间排列；轨道／选项为 34／28px，圆角为 8／6px，选中裁切不回到胶囊。返回按钮在 form 内也只导航；切换与扫描、上传、重试的禁用及清理保持一致。
- 核验真实伙伴、安装、版本、固定摘要、工具及试用引用；无自动安装、授权或发送，无由计数、旧测试或猜测派生的可用状态。
- 定向测试、类型与样式检查按改动执行；实际视觉与原生交互验收需用户授权，自动化通过与真实验收分别报告。未检查的状态明确留作边界。
