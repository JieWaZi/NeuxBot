# 插件资源

## 事实与归属

资源库聚合插件、独立技能和独立连接器。插件资源保存统一本地身份，不区分公私或伙伴归属；版本保存不可变内容、摘要、原始清单及来源；伙伴安装保存明确版本和启停；共享设置保存唯一修订及加密密钥；独立共享账号保存代次与加密交付材料。伙伴之间不复制账号或配置。

插件可从自有插件库准备，或从同一次 GitHub／ZIP 技能扫描中选择至少两项技能创建本地技能插件；不提供任意插件目录或 ZIP 导入。全局插件列表聚合可信目录、实际安装和本地技能插件，按来源身份去重。实际安装在前、未安装本地技能插件其次、未安装目录在后；本地入库不计入安装数，最后一个伙伴卸载后仍保留本地资源。停用仍属于已安装，下架但保留安装的来源仍可管理。仅准备或授权但尚未安装不计为已安装；最后一个伙伴卸载后，来源若仍在目录则作为未安装条目展示。展示名称可以重复，运行时技能身份使用 SKILL.md 的声明名称；同名同内容只投射一份，不同内容拒绝接纳。

包内技能和 MCP 是版本派生组件，不登记为独立安装资源，也没有独立编辑或升级入口。旧供应商 provider 声明不提供兼容执行或内容转换；旧资源可以卸载或删除，使用时需从插件库安装当前标准包。

业务数据库使用统一 `dbhelper.NewDB()` 与模型 AutoMigrate 初始化，不另设历史列、索引或数据迁移流程。插件来源身份由当前模型的唯一索引约束，不自动合并资源、覆盖账号或改写包快照。

## 来源与交付

正式目录只接收自有目录发布的标准包。目录包来源文件使用独立插件仓库的统一 `provenance.json` schema，分开记录业务上游、封装维护者、隔离依赖及本地素材；当前规范在插件仓库 `docs/PROVENANCE.zh-CN.md` 和 `schemas/provenance.schema.json` 维护，应用不另造供应商来源字段。`server/internal/plugins` 的清单解析、完整性校验、技能/MCP 归一化和原生目标派生是内部交付能力，不是面向用户的任意插件导入接口。自有包只接受根 `plugin.json` 的 Agent Plugins 1.0.0 清单，以及固定 `skills/` 和 `mcp.json`；OpenAI 展示信息只读根 `extensions.com.openai`，NeuxBot 声明只读 `extensions.com.neuxbot`。不接受旧清单目录、旧命名空间或原生来源引用。解析快照携带 `neuxbot-plugin/1`，缺少或不同契约的旧快照不能接纳为安装、诊断或执行目标，也不自动迁移或清库。目标适配仅转换已经明确支持的字段，不承诺跨端语义等价。普通 Skill/MCP 目标只接收已经验证的组成，身份和配置不写回包。

展示资料由根 `extensions.com.openai.interface` 与显式 `.neuxbot/presentation.json` 本地化资料归一化，作者身份仍保留原始声明。包内 PNG、JPEG、GIF 和静态 SVG 可作为软件图标，读取限制为 256 KiB；SVG 拒绝脚本、事件、样式、外部引用与 `foreignObject`，未声明图标时由界面使用默认图形；显式声明的包内图标缺失或无效时拒绝该包，不忽略声明继续安装。根 README 的内置阅读限制独立为 1 MiB 的 UTF-8 Markdown，提供 available、empty、missing、too-large、invalid 状态；超限完整快照保留，可经固定来源原文接口下载。预览按渲染高度裁切，完整弹窗复用静态 Markdown，不截断源码。列表只返回正文状态，完整正文在详情按版本读取。技能正文仅通过已发现组件键读取；已安装版本先复验完整摘要，目录预览只读取与同一发布归档绑定的公开资料文件。

插件详情中的技能进入固定版本只读详情页，独立技能列表不混入插件组件；身份头、元数据与 Markdown 正文复用技能详情页的阅读组件，不提供资源文件、历史页签及编辑、更新或删除入口。已安装 URL 保留插件版本与组件键，目录预览固定目录键、来源提交、归档摘要和组件键；返回保留实际父入口上下文。独立技能页按伙伴安装行、SKILL.md、信息组织，按用户要求保留 SKILL.md／资源文件／版本 Tab，提供真实文件与版本差异能力；不增加独立管理或卸载 Card。技能读取接口保留实际资源清单与版本快照。资源路径相对该技能目录，清单保留目录、字节数、内容摘要和执行位；只在选择文件时读取正文，预览上限为 1 MiB，二进制使用 Base64 表达。读取拒绝清单外路径、目录和符号链接；声明为插件根目录的技能还会排除插件清单、共享配置与其他组件。已保存插件的历史只包含同一组件键实际保留的插件版本，查看历史时重新核对相应不可变内容；目录技能只显示当前声明版本，不伪造本地历史。

自有目录安装包先解包到受管暂存区，来源与完整摘要绑定；摘要使用带长度的路径记录和逐文件摘要，内容不能伪造另一条文件边界。准备时复验相同快照，再写入按完整摘要寻址的内容目录。清单中的 repository 只是作者声明，目录包身份来自经核验的分发目录项，不接受用户路径或任意插件暂存令牌新增目录资源。本地技能封装只接收既有技能扫描批次及其中的候选标识，复用原批次完整性校验。

默认软件目录来自 [独立插件仓库的 HTTP Release 清单](https://github.com/JieWaZi/neux-plugins/releases/latest/download/catalog.json)。目录检索只读取有界元数据；完整清单及 HTTP 校验信息按来源隔离，原子保存到应用数据目录的 `plugins/catalog/`。每次 Core 启动后后台同步一次；用户可通过“检查更新”显式重新核验同一来源，合并并发请求。有缓存时普通查询立即返回旧快照，搜索、分页、窗口恢复及页面切换不触发额外远端下载。支持 ETag 与 Last-Modified 条件请求，304 复用原内容；同步完成后通过既有插件事件刷新目录查询。目录详情遇到失效的公开资料地址或摘要时，允许一次按原可信来源刷新目录并重解析条目，只重试新的公开资料；安装准备遇到归档地址或摘要失效时，独立恢复目录并只重试新归档一次。两类恢复均合并并发，不增加轮询，详情始终不下载 ZIP。绑定具体提交和摘要的原文与技能请求不静默换成新版本。来源不可用或响应损坏时保留旧缓存并显示 stale、时间及稳定错误；目录和归档获取失败按分发错误表达，不复用配置、认证与程序就绪提示。首次无缓存的并发查询合并等待同一次同步，失败不伪装成零条目。同步使用 Core 取消边界，退出时取消并等待请求结束。`ALLY_PLUGIN_CATALOG_URL` 可明确指定 HTTP 镜像或本地目录；旧应用资源目录不覆盖默认在线来源。安装按同一目录项的 sourceCommit、archiveURL、archiveSHA256 和 packagePath 下载并校验 ZIP，半包或摘要错误不发布。运行期间没有 Git 可执行文件依赖，应用构建不携带插件安装 ZIP。

ZIP 解开后保存完整来源根，自有插件直接包含实际能力。包内引用始终限于同一不可变快照，路径穿越和访问包外内容被拒绝。原包身份与派生目标的名称、版本、摘要及组成分别保留。

目录索引和独立公开资料均固定为 `schemaVersion: 1`，采用当前标准包字段及目标解析契约，不提供其他版本的读取兼容。目录详情、README 和 SKILL.md 只读取发布时生成的独立公开资料文件，不要求安装、配置、认证或授权程序就绪，也不下载完整安装 ZIP。目录项通过 `detailsURL`、`detailsSHA256`、`detailsSize` 声明资料，三项必须完整；资料最多 4 MiB，并绑定同一 `sourceCommit`、`archiveSHA256` 和 `packagePath`。资料只包含公开元数据、本地图标、双语 README、技能说明及连接器公开地址，不包含命令、参数、环境变量、请求头或秘密绑定。客户端校验摘要、大小、协议及来源绑定后按内容摘要缓存，并合并并发下载；已声明资料损坏或不可用时准确报错，不隐式下载 ZIP。未声明完整公开资料或使用旧工件版本时明确拒绝，不下载归档补详情。安装准备始终下载并复验完整 ZIP，从真实包重新解析执行能力，不能将公开资料作为安装或执行依据。目录技能通过资料只读展示 SKILL.md，其他资源需从实际安装内容读取。

HTTP 200 仅表示下载完成，字段结构或标准包契约不符仍明确拒绝，不能只改版本数字使旧内容可执行。本地跨仓库验收通过[显式开发入口](../development/build-and-release-cn.md)构建真实标准三包，由同一开发进程拥有回环下载服务；输出目录持久保留并作为稳定来源身份。它不替换正式默认源，也不将本地来源伪装成正式目录。切换目录不改写旧版本、伙伴关系或账号材料；旧包与新目录资源分别存在。

旧安装恢复不能通过补契约标记、重命名版本、忽略回退检查或覆盖同版本不同摘要完成。先从已验证的新目录正常准备、授权并为原伙伴安装当前标准包，复核实际启停和账号，再由用户明确确认旧引用的卸载或删除。旧供应商私有目录不自动导入新的包内身份目录，已有文件不代表新共享账号已验证；重新授权需由包内真实流程完成。正式源恢复则要求独立插件仓库发布符合当前契约的目录、公开资料与完整归档；本地验收不能代替远端发布。

独立仓库在 `plugins/<name>/` 下自行维护一套完整 OpenAI/Codex 标准包，可以参考官方开源示例封装，并按许可保留实际复用内容、来源和修改记录。认证授权由包内桥接定制，宿主复用通用协议；不分别维护 Codex、Claude 两份来源或空引用入口。发布构建从本仓库固定快照生成完整 ZIP，不依赖临时获取上游插件内容。原生目标配置从实际清单推导，执行只校验并交付当前目标所需的配置。供应商凭据与交付材料由独立共享账号加密保存，不进入公共结果。

业务插件、专用授权流程、程序依赖、来源锁与发布归独立 neux-plugins 仓库维护。宿主只负责通用目录、完整性校验、版本安装、配置、授权桥接与 Runtime 交付，不内置供应商 CLI 或维护供应商授权分支。插件包保留各自第三方许可与 provenance，见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。

公开说明来自逻辑插件自身的业务 README，中文使用 `README.zh-CN.md`，英文使用 `README.md`，缺中文文件时回退英文；仅介绍插件能力、权限前提和使用示例，不写伙伴、宿主安装入口或聊天引导；维护与适配细节进入开发文档和声明。图标由标准 `extensions.com.openai.interface.logo` 声明包内资产，支持明暗资产及品牌色；附加展示文件承载中英名称／简介、与标准 `defaultPrompt` 等长的提示翻译及静态连接说明。提示词归一为唯一数组，capabilities 仅为作者能力说明，不授予实际权限。目录使用真实 category，不按名称猜测；缺失资料隐藏对应区块，目录同时返回经校验的小图标和语言资料，安装前无需下载完整归档即可显示。用户自定义名称优先于默认本地化名称。正文与原文查询的缓存身份包含语言，避免切换语言或版本后串内容。

本地技能插件将选中技能的完整资源树放入标准 `skills/` 目录，只生成当前标准根清单；不继承来源根的 MCP、认证、命令或其他插件声明。名称和可选说明属于用户创建资料，技术名称与新资源身份关联。重复技能声明名、相互包含的技能目录或包含其他技能的所选目录明确拒绝，不静默扩大或缩减选择。必要的来源根和祖先 LICENSE、COPYING、NOTICE 等文件及许可目录保留到 `docs/source-licenses/`，所选技能内的许可随资源树原样保留。`.neuxbot/skill-source.json` 与版本来源记录保存来源类型、明确的 Git 地址／请求引用／子目录、所选相对路径与摘要以及许可路径索引；ZIP 不记录本机上传路径，不推断作者、统一许可或真实提交，也不冒充正式上游 provenance。

本地技能插件使用 `local-skills:<资源标识>` 来源和既有插件资源、不可变版本及内容存储，不建立新作用域或独立技能记录。入库成功消费扫描批次，失败沿原扫描边界保留批次。创建不建立伙伴关系；伙伴入口随后通过既有显式安装操作安装当前版本。其后配置准入、启停、卸载和删除复用插件生命周期；本地来源不参与正式目录更新。

## 安装与卸载

独立技能先通过 GitHub 或 ZIP 扫描并导入本地技能库，再通过独立安装操作关联一个或多个伙伴。导入只保存技能包与不可变版本，不建立伙伴关系；安装失败保留已经入库的资源，重试安装不覆盖已有启停选择。技能包由本地库统一维护，伙伴安装独立保存；库查询读取全部受支持资源，伙伴查询及执行只读取真实安装关系。展示名称和用户分类属于技能包资料，更新不修改 SKILL.md 或生成内容版本。

从伙伴移除独立技能只删除该安装关系，技能包、全部版本及其他伙伴的安装保持不变；删除伙伴同样只清理它的技能安装关系。只有明确删除技能库资源时才删除技能包、全部版本及所有伙伴关系，操作前核对已确认的实际影响数量。详情读取完整安装伙伴名单，列表使用最多四个真实伙伴的有界预览，两者不共用预览窗口。内部系统任务知识由运行体系维护，不进入普通技能库列表，也不因伙伴移除或产品列表过滤而删除内容。

未安装插件点击条目直接进入详情页。点击安装后展示 NeuxBot 与插件图标，先选择一个或多个伙伴，再处理必要配置与共享认证。当前会话明确返回二维码、外链或验证码动作时，安装面板显示对应交互；普通 URL 不自动生成二维码。支持二维码的挑战优先内联显示；生成期间展示同位置加载状态，提供刷新图标，刷新等待旧会话取消后再发起，不提供重复显示按钮。授权信息简短说明共享范围，等待不误报缺权限，完成阶段通过既有事件更新，真实账号核验通过后才为所选伙伴安装。准备、授权和数据库安装关系分别处理；取消选择不会产生占位关系，也不会清除已完成的共享认证。批量安装逐伙伴返回结果，重复安装保留原版本与启停。

安装授权弹窗在首次状态或授权动作尚未返回时保留交互区域并显示加载提示，外链和验证码也遵循同一等待状态。二维码或授权码居中展示，加载说明、刷新及验证码说明放在展示区域下方，“打开授权页面”使用底部撑满内容宽度的主操作按钮，布局不依赖桥接动作的返回顺序。未核验账号使用“连接账号”入口，失败、过期或取消后提供“重新授权”；等待中的安装面板只保留当前挑战动作，不重复展示重新授权或取消按钮。关闭、Escape、遮罩关闭或卸载组件时取消本弹窗仍在等待的会话，启动响应晚到也须补偿取消。已完成认证和自动安装成功关闭不撤销共享账号；二维码刷新仍先结束旧会话再启动新会话。

普通设置更新验证所有保留安装使用的版本。内容继续按完整摘要保存不可变版本，准备不会改变伙伴安装，相同版本号不能覆盖不同内容。统一列表的未安装条目展示目录发布资料，已安装条目与伙伴详情读取实际安装的固定版本；准备但尚未安装的新版本不能替换其内容。全局存在多个安装版本时，概览仍从真实安装中选择，具体伙伴始终读取自身版本。第三方插件显示官方来源版本，自有插件使用自身版本。官方远程服务显示“官方托管”，不将内部包装版本当作远端部署版本。

伙伴卸载全局资源保留其他伙伴关系；整体删除先确认实际影响集合。卸载同一插件的最后一个实际安装时，先取消未完成授权、等待包内桥接进程退出并清理其本机共享授权，再删除关系；删除没有安装的资源也会检查该插件是否仍被其他伙伴使用，避免保留孤立授权。关闭的安装仍属于保留引用。清理期间阻止新安装和新执行取得身份，已有工作占用会阻止最后引用删除；其他伙伴仍有安装时不清理共享账号。桥接清理在数据库事务外执行，清理失败保留原关系供重试，准备或首次安装不自动清除已经完成的授权。内容与 PLUGIN_DATA 在数据库引用和活跃执行占用均消失后回收。准备、接纳与回收由同一进程内内容边界协调，回收不穿过受管子目录链接。

## 执行与连续对话

资源配置变化使用 `plugins.changed`；执行占用、当前回合引用及其释放使用 `plugins.usage.changed`。安装和授权行为由原模块维护，使用引用不会重新触发授权校验。管理界面可响应两类事件，聊天候选只响应资源配置变化；隐藏聊天暂停候选查询。共享刷新与恢复规则见[查询与事件所有权](notifications-and-work-board-cn.md#查询与事件所有权)。

Codex 与 Claude 的原生配置根和其 `worktrees` 下的独立工作区分别校验。工作区内的受管模型账号、隔离运行目录和聊天能力摘要不能仅因嵌套在原生配置根下被拒绝；摘要仍限定为当前工作区的固定私有路径或本次隔离账号目录。全局配置根、插件缓存、`worktrees` 集合根以及中间符号链接不属于该工作区边界，不能通过目录嵌套取得共享原生状态的写入权限。

Execution 热准备读取已发布版本、目标组件元数据、启用与必要配置声明；ProviderRuntime 冷获取再核对实际版本、配置、内容和身份租约，按支持的 Skill/MCP 投射交付。当前不提供应用原生整包交付成功路径，native-only 组合在实际入口明确拒绝。外部 CLI 原生插件由 CLI 自身管理，不同步为 NeuxBot 的资源或安装关系。

模型账号和插件共享认证分别由原有账号与资源所有者提供，不因插件交付覆盖所选模型身份。插件环境只能使用已核准的组件、端点及目标，受限入口不自动取得包内其他能力。

资源普通变更由下一轮读取新声明；已接纳进程保留原版本与实际租约，不覆盖活动消费者的物理目标。可重载时只重开进程并恢复原 session，不兼容时才沿既有历史接力替换；原生配置根或主体变化继续隔离。用户级默认技能发现与应用受管技能分别归属。

自动按需能力来自伙伴实际启用的自有插件；本轮明确引用通过 pluginIds 单独提交，并只附加本轮选择提示。系统安装只通过插件库界面执行。`allycli capabilities` 不再公开系统插件搜索、详情、安装与安装状态操作，系统 Skill 也不再要求聊天安装经过 allycli。聊天中的原生安装由当前 CLI 自己执行并落入与外部相同 CLI 共用的原生插件环境，不创建系统安装关系。

STDIO 配置经过 Core 的无协议转换启动模式设置 cwd，保持原始 argv、env 与三个标准流；没有 shell 字符串拼接。MCP 传输按适配器注册的支持范围准备，实际握手不支持时明确拒绝；探测失败不能让已启用的 Skill／MCP 静默消失。派生服务使用稳定组件授权身份并继续接受现有 MCP 白名单限制。受限入口只交付明确获准的组件；MCP 白名单不授予包内技能的命令执行能力，也不构成 shell 沙箱。

消息保存明确引用的插件展示资料，执行保存实际交付版本、配置修订、账号代次、身份及组件，不保存凭据。普通历史执行重试链已删除；提交重传仍核对原输入身份和回执，工作流等领域保留自身真实重试。

## 发现新版与统一更新

更新状态由当前可信目录快照与实际伙伴安装派生，不建立独立更新表。目录条目必须精确匹配资源来源，只有包的有效语义版本高于实际安装版本才提示“可更新”；同版本、目录回退或未知版本不自动当作升级。包的比较版本用于校验与固定目标，用户展示资料继续使用明确的业务上游版本，不把辅助程序版本作为业务服务版本。普通本机列表与详情只读取已缓存目录和安装，不等待网络、不下载归档；目录尚未就绪或失效时保留安装内容，明确表达未核验或陈旧，不能声称已是最新。

已安装插件条目与详情提供“可更新”入口。资源列表在搜索行提供 Info 图标，悬停不增加灰色背景；悬停、聚焦或点击后在交互浮层中显示上次成功检查时间与刷新图标按钮，尚未核验时明确说明。刷新点击即检查更新，处理中禁用；浮层允许指针移入点击及键盘操作。输入框后不单独放刷新按钮，检查时间不占用额外常驻行。检查使用现有条件请求与来源缓存，成功和失败均经插件资源事件对账，没有常驻轮询。检查只刷新目录，不准备内容，也不改变伙伴关系。

一次更新覆盖该插件全部已安装伙伴，不提供选择伙伴的控件。更新弹窗说明影响范围，先核对确认的目录归档摘要、准备不可变目标，再处理目标版本要求的共享配置和真实授权。目录在此期间变化、摘要不符、信任未确认或授权失败均不能静默改用其他目标。准备成功不等于完成更新，也不能提前替换实际安装展示。

最终提交通过独立更新用例执行共享配置与版本切换事务，完整比对确认时的安装集合、每个伙伴原版本、配置修订和账号代次，并要求全部切换至同一目标。确认后新增安装、卸载或改版时整次拒绝，刷新后由用户重试，不把旧集合当作全部伙伴。全部伙伴的原启停状态保持；任一检查失败时配置和安装一并回滚。已接纳工作继续使用原先冻结的版本、配置与身份，后续工作才使用新版本。部分历史版本、共享配置和身份占用继续遵守原有内容与授权边界。

## 共享认证

普通插件浏览只窄读版本与安装，不查询配置或账号表；静态详情另外窄取配置修订和账号代次。两者从现有授权管理器读取当前 Core 内最近一次真实核验的公开身份摘要；不创建或替换授权桥接、不启动供应商程序，也不遍历完整包。摘要携带 `checkedAt`；Core 重启、配置或桥接版本切换后，未核验的身份保持未确认，不能据此提示授权已失效。退出成功记录明确不可用的摘要，核验失败清除旧的可用摘要；身份重置前发起的迟到查询不能恢复旧摘要。该摘要仅服务展示，不保存凭据，也不能作为安装或执行准入依据。授权操作、安装与版本切换按其管理流程校验固定内容及真实身份；既有授权完成和安装等资源事件负责刷新展示，不增加状态轮询。聊天引用按实际安装和启停关系展示固定版本，不因未确认授权隐藏引用。聊天入口不对插件、MCP 或 Skill 发起远端健康或授权预检，实际可用性由智能体调用时的结果表达。普通详情仅按固定文件名有界读取对应语言的 README；短读与内容回收共用互斥边界，释放时不触发全库垃圾回收。组件直接采用已保存快照，不通过重新扫描补齐旧版本元数据；原文下载与技能文件读取仍保留各自的固定内容校验。

`internal/plugins/authorization` 统一管理会话、Core 生命周期、取消、工作占用和安全摘要。插件在根 `extensions.com.neuxbot.authentication` 声明 `plugin-command` 与 `neuxbot-auth/1`，通过可选 `preferredAction` 指定加载偏好，通过 `bindings` 精确限定目标、MCP 键、HTTPS 地址和请求头，宿主用固定包内入口及独立 argv 启动，供应商 CLI 和扫码解析归包内桥接。宿主先执行严格 `auth/initialize` 握手，冻结 operationId、pluginId、versionId、digest、configurationRevision 和 accountGeneration，再调用 auth/start、status、cancel、resolve、logout 的逐行 JSON-RPC；challenge/state 通知必须同时匹配 operationId 和 sessionId；URL、二维码、验证码按本次 actions 渲染，不按插件名称判断。auth/start 首次挑战前允许 150 秒准备受管资产与启动进程，status、resolve、logout 等普通请求仍限 30 秒；收到挑战后改用其实际期限。deadlineAt 与官方 expiresAt 分别表达本机等待和上游期限，取消在准备和扫码阶段均立即传递并等待真实进程退出，终态清除临时挑战。 `show-qr.value` 的普通字符串作为二维码原始载荷编码；严格的 `data:image/png;base64,...` 则直接展示官方 PNG 原图，宿主限制解码后不超过 256 KiB、宽高各不超过 1024 像素，并完整解码、拒绝尾随数据。SVG、其他 MIME、非标准 Base64 以及损坏或超限图片均被拒绝；远端 URL 继续作为扫码载荷编码，不作为远端图片加载。

授权挑战可声明 `notice.messages` 阶段提示，使用 `en`、`zh-CN` 语言键，每条最多 2 KiB。前端按界面语言选择纯文本，缺中文时回退英文，以统一黄色提示卡展示；没有声明则不展示。提示只属于当前等待挑战，后续挑战未声明时移除，取消或终态一并清除。飞书包在自身授权展示文件声明首次设置后的二次扫码说明，并仅在应用设置挑战发送；宿主不根据插件名称、URL 或账号字段猜测提示内容和阶段。

授权完成与安装准备负责调用桥接 resolve，严格核验组件、目标与端点，并将私有交付材料加密保存到独立 PluginAccount，以账号代次做条件提交。授权在独占登录完成且进入就绪前保存材料；安装按拟提交配置生成材料，最终短事务同时核对配置修订与账号代次。显式登录重新验证所选版本和所有仍安装版本，包含停用关系；任一交付失败清除旧身份材料但保留安装，不伪装外部登录已回滚。普通状态查询只读取和核验身份，不生成或写回材料，迟到查询不能恢复已退出的秘密。材料绑定固定版本及授权端点，不因普通配置修订或 Core 重启而触发聊天重新解析。聊天取得本地身份占用后才读取当前交付材料，并核对已经冻结的配置事实；随后加载 MCP、Skill，不启动授权桥接，不调用 status 或 resolve；材料缺失或过期不作为聊天准入条件，由智能体实际调用报告失败。秘密绑定不进入 HTTP 公共结果、聊天、日志或索引，不能修改已核准端点或 Runtime 身份。PATH 只能由插件私有已核验目录和宿主原有受信路径组成。多个技能 CLI 的 PATH 按接纳顺序合并去重，私有程序目录统一位于继承路径之前，避免系统同名程序覆盖后接纳插件；其他同名环境变量的值不一致时仍拒绝执行。STDIO MCP 的环境绑定只交付对应连接器，不合入技能共享环境。不同插件按资源身份隔离私有数据与账号；同一插件所有伙伴共用身份租约。显式 MCP 连接测试优先复用匹配版本的桥接与共享身份；桥接创建或切换遇到占用时，通过现有会话所有者回收相关闲置消费者后重试，活动工作保持原占用。热消费者持有资源占用，每轮执行用途独立更新并在结束时清除；授权、退出和最后卸载通过现有会话所有者先关闭相关闲置消费者，活动执行继续返回忙碌，不新增平行会话注册表。退出成功清除私有交付材料，重新授权替换对应材料。桥接指纹包含完整内容摘要及实际包路径，版本只能在无授权等待和执行占用时更换；旧桥接与新桥接不能同时绕过同一共享身份边界。绑定可以作用于同一自有标准包，也可用于自有包支持的明确目标；有明确绑定而当前目标未匹配时明确拒绝。MCP 标准认证支持 none；api_key 必须具有显式秘密配置或精确驱动头绑定，oauth／mixed 及本轮未支持的执行能力明确返回不支持，不降级成匿名服务。当前 GitHub 包只声明 Codex、Claude 两个授权目标，不代表所有 Skill/MCP 目标都能取得其凭据。未带授权绑定的 Codex 标准包直接交付根标准目录；需要包内驱动头绑定的 Codex 走精确 MCP 投射，不能借用不确定生效的兼容 overlay。Claude 私有派生只写 `headers` 环境引用的无秘密模板；真实凭据仅进入私有执行环境，诊断日志按当前秘密值脱敏。未绑定头与其他配置仍正常校验，托管 apps 的独立授权保持其自身边界。宿主明确拒绝旧供应商 provider 声明，授权与依赖准备由当前标准插件包通过同一协议完成。

包内授权程序、MCP 和其他原生执行组件均纳入受管预检的执行确认，目录准备结果返回权威 `trustRequired`。未确认版本不能启动授权桥接，包括直接授权接口。桥接取消先发协议请求并给上游停止窗口，随后回收受管进程组及关闭读取，避免子进程持有 stdout 造成永久等待。

## 接口与前端

执行准备和管理详情使用不同读取职责。热声明读取伙伴启用安装的固定版本、已发布目标组件、摘要、信任、配置修订、账号代次，以及实际选择需要的普通配置和已配置秘密名称，不读取秘密值或启动授权桥接。冷获取重新核对安装、版本和配置，再读取完整执行包、验证内容并解密实际交付材料；变化时准确重读或冲突。公开 Package、版本及目录响应使用业务字段集，配置入口通过公开的是否需要配置标记判断，不透传源存储路径、原生执行配置或授权命令，内部完整包继续持久保存。

输入区的插件候选属于当前所选伙伴的轻量引用，单独读取已启用安装的资源身份、名称、简介及固定版本身份；不扩大伙伴列表，不读取管理配置、包内容、账号或使用状态。非空读取以一次伙伴存在性查询及三次单表窄列查询完成，在短读事务中固定安装、资源和版本的一致性。`plugins.references.changed` 只说明安装、启停、版本和展示资料变化，按伙伴或已引用资源精确更新；首份读取未确认时保留相关展示变化。共享配置、授权、使用引用及普通消息终态不触发候选重取；完整管理接口及使用状态保留原行为。

插件接口在 `server/apis/plugins`，独立技能与连接器通过各自全局 LibraryRouter 和伙伴操作复用同一用例。完整 HTTP 契约由 [OpenAPI](../../server/openapi.json) 生成前端 Client；不手工维护第二份协议声明。

资源库通过左栏分类组织插件、技能和连接器。插件统一使用 `GET /plugins/browse` 的公开窄摘要；前端每批至多 100 条、完整读取成功后按真实分类展示，已安装快捷项独立读取无搜索的完整安装摘要。列表没有双页签、选择列、批量工具栏或使用数第三行，维护操作进入详情。浏览不读配置秘密或管理详情，不下载归档或执行包程序；目录未知时保留真实安装，完整总数保持未知。技能页直接对应 OpenBot SkillLibrary／LibraryRow：统一两行条目、整行搜索与相邻添加入口，仅展示 GitHub 同步与 ZIP 上传的独立技能，不展示插件技能及内部系统技能，也不按安装来源分组、筛选或追加来源第三行。用户分类选项统一保存在 `resource_categories`，以 `type` 区分插件、技能与连接器，同类型内按实际名称唯一；每个资源的 `categories` JSON 列保存多选名称，空数组为未分类。编辑字段可选择已有分类、输入过滤候选，或回车／点击创建新分类；草稿随所属表单保存，分类词库与资源更新在同一事务提交。移除资源上的标签不会删除已有分类选项，插件作者的标准目录分类仍独立保留。技能按每个已选分类展示，未分类资源单独成组；按 SkillLibrary 每组预览六项，“查看全部”进入分类后每批 24 项并在接近滚动底部时自动追加。分类更新复用现有独立技能更新接口，未传保持原值、空数组清空，不修改 SKILL.md 或不可变版本。内部系统技能仍由运行时管理，不因产品列表隐藏而删除其事实。真实安装与伙伴启停保留，管理进入详情；连接器使用同一 catalog 两列轻量列表与整行搜索，列表仅展示独立连接器，插件 MCP 从所属插件进入详情，保留真实安装与伙伴启停，不再提供来源分组、来源筛选或批量工具栏。添加连接器进入同一资源 Scene 的独立表单页，保留传输配置、密钥和信任确认；全局新建入库，伙伴入口仍创建自身连接器并安装启用，不因页面结构改变所有权。连接器详情只按现有接口展示当前伙伴状态或真实安装计数，不从计数推导伙伴名单；CLI 兼容阵列不在页面展开，实际传输兼容仍由后端与执行边界维护。唯一视觉依据见[UI 标准](../development/resource-ui-cn.md)。

静态详情不携带配置字段、值、密钥标记或就绪结果。设置、安装和更新操作显式读取配置及预检结果；账号 GET 只读缓存，在线核验使用显式 check。显式账号核验、授权开始和退出绑定 versionId、配置修订与账号代次；授权会话 GET 以 versionId 与 sessionId 读取缓存，取消使用原发起上下文补偿迟到会话。安装授权重试从读取账号并发上下文到发起授权共用一次提交锁和处理中状态，后续失败覆盖先前失败，重试成功后清除原错误。失败会话只按 Core 白名单稳定错误码查询生成的本地化目录，依赖准备失败与账号认证失败分别表达；未知码回退为认证未完成，不展示原始供应商输出，也不将未核验账号视为成功。配置保存使用 expectedRevision 并验证仍保留的实际版本；安装和独立更新各自核验目标版本、配置修订及账号代次。普通配置保存不切伙伴版本，更新通过独立 POST 用例原子核对完整伙伴集合；退出说明共享影响，不混同停用或卸载。

详情按当前入口的固定版本展示标准资料、真实连接与账号、技能、MCP、全局安装伙伴及信息。旧包或解析契约不受支持时，管理详情仍返回实际资源、版本与安装关系，以 packageStatus=unsupported 和稳定 packageErrorCode 表达不可用；页面显示重新安装提示，保留实际伙伴与卸载／删除。此时不读取包内说明，不展示或触发安装、更新、启停、配置、组件和试用；组件与执行接口继续严格拒绝，不把旧包降级为可执行内容。没有真实内容不创建空区块；伙伴页只展示自身版本与启停／卸载。纯重命名在页头提供维护入口，存在配置或账号才显示连接与设置。开发者、业务版本、许可与源码优先来自固定 provenance.upstream；未声明业务版本时隐藏，不显示包装或授权辅助程序版本。标准支持链接、主题图标和连接步骤如实呈现；界面不展示作者能力说明，也不能据 capabilities 推导访问控制。托管仓库链接显示拥有者与仓库名，不能把托管域名作为作者身份。

标准 defaultPrompt 仅填入独立聊天草稿。全局入口先选目标伙伴，伙伴上下文使用当前伙伴；没有伙伴时提供创建入口。只有真实已安装且启用时才附加插件引用，否则保留示例文本并提供安装入口。安装取消和创建取消保留当前选择，不自动发送，不覆盖已有会话草稿。

连接器详情与技能、插件共用试用卡。独立连接器使用产品默认提示并引用 connector；插件 MCP 引用所属插件，要求所选伙伴已启用且安装版本与当前预览一致，目录预览还需核验本地版本与固定提交、归档摘要。全局详情先选择伙伴，再按真实伙伴资源与安装关系判断；未知、未安装、停用或系统场景资源仅说明当前原因，不借试用自动安装、启用或发送。场景可选性复用聊天的连接器策略规范化。试用只建立独立聊天草稿，输入区等待真实资源资料后一次性写入已有 Mention，不根据旧测试结果推断当前可用性，也不触发远程连接或授权预检。详情信息顺序及局部测试、诊断和删除入口以[UI 标准](../development/resource-ui-cn.md)为准。

插件技能和连接器均从所属入口进入固定来源只读详情页，保留版本、目录来源与伙伴上下文；插件连接器仅在所属插件中展示，仍是所属插件版本的派生组件，不建立独立资源或独立启停。普通查看不执行包内容或启动授权。目录组件只读 schemaVersion 1 公开资料，不以归档补齐遗漏组件。显式“测试连接”仅初始化 MCP 和发现工具，不调用业务工具；要求实际版本已信任，复用精确配置、账号代次、内容与身份租约。请求头和环境只公开名称，URL 去除用户信息、查询和片段，不公开参数原值。诊断结果仅在当前 Core 有界缓存，配置、账号代次、驱动或身份变化后失效；迟到结果不能覆盖新身份。HTTP 诊断不接受重定向，SSE 消息端点必须同源。秘密、原始启动参数与私有材料不进入公开结果。

所有接口与 DTO 以生成 OpenAPI 为准，状态保存在 TanStack Query；资源与账号提交复用既有 Core 事件，不建立页面轮询或另一套安装、账号注册表。只读管理扩展与 GitHub 仓库列表属于后续阶段，本轮没有对应执行入口。
