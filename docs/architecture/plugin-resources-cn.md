# 插件资源

## 事实与归属

资源库聚合插件、独立技能和独立连接器。插件资源保存稳定身份与归属；版本保存不可变内容、摘要、原始清单及来源；伙伴安装保存明确版本和启停；共享设置保存唯一修订及加密密钥。伙伴之间不复制账号或配置。

系统插件仅从自有插件库准备后安装到伙伴，不提供上传、本地目录或 ZIP 导入。全局发现与实际安装分别查询。“我的插件”只展示至少存在一条伙伴安装关系的资源，搜索、总数与分页均按同一安装条件在数据库中过滤；停用仍属于已安装，最后一个伙伴卸载后退出该列表。仅准备或授权但尚未安装的资源仍可供插件库关联和后续安装，不显示在“我的插件”。展示名称可以重复，运行时技能身份使用 SKILL.md 的声明名称；同名同内容只投射一份，不同内容拒绝接纳。

包内技能和 MCP 是版本派生组件，不登记为独立安装资源，也没有独立编辑或升级入口。当前模块按新数据库建立目标结构，不包含旧供应商 provider 声明的兼容执行或数据迁移；旧资源可以卸载或删除，使用时需从插件库安装当前标准包。

## 来源与交付

系统只接收自有目录发布的标准包。来源文件使用独立插件仓库的统一 `provenance.json` schema，分开记录业务上游、封装维护者、隔离依赖及本地素材；当前规范在插件仓库 `docs/PROVENANCE.zh-CN.md` 和 `schemas/provenance.schema.json` 维护，应用不另造供应商来源字段。`server/internal/plugins` 的清单解析、完整性校验、技能/MCP 归一化和原生目标派生是内部交付能力，不是面向用户的任意插件导入接口。自有包优先采用标准清单与组件目录；目标适配仅转换已经明确支持的字段，其他原生组件保留其来源与执行边界，不承诺跨端语义等价。普通 Skill/MCP 目标只接收已经验证的组成，身份和配置不写回包。

展示资料由各格式的 `interface`、公开清单字段及本机表现扩展归一化，作者身份仍保留原始声明。包内 PNG、JPEG、GIF 和静态 SVG 可作为软件图标，读取限制为 256 KiB；SVG 拒绝脚本、事件、样式、外部引用与 `foreignObject`，无效图标使用默认图形。根 README 的内置阅读限制独立为 1 MiB 的 UTF-8 Markdown，提供 available、empty、missing、too-large、invalid 状态；超限完整快照保留，可经固定来源原文接口下载。预览按渲染高度裁切，完整弹窗复用静态 Markdown，不截断源码。列表只返回正文状态，完整正文在详情按版本读取。技能正文仅通过已发现组件键读取；已安装版本先复验完整摘要，目录预览优先读取与同一发布归档绑定的公开资料文件。

插件详情中的技能弹窗展示固定版本的元数据与 Markdown 说明正文，名称、数据源和描述复用技能详情页的阅读组件；资源列表中的插件技能进入独立只读详情页，显示元数据与正文，不提供资源文件、历史页签及编辑、更新或删除入口，URL 保留插件版本与组件键。独立技能页继续提供元数据、资源文件与历史。技能读取接口保留实际资源清单与版本快照。资源路径相对该技能目录，清单保留目录、字节数、内容摘要和执行位；只在选择文件时读取正文，预览上限为 1 MiB，二进制使用 Base64 表达。读取拒绝清单外路径、目录和符号链接；声明为插件根目录的技能还会排除插件清单、共享配置与其他组件。已保存插件的历史只包含同一组件键实际保留的插件版本，查看历史时重新核对相应不可变内容；目录技能只显示当前声明版本，不伪造本地历史。

自有目录安装包先解包到受管暂存区，来源与完整摘要绑定；摘要使用带长度的路径记录和逐文件摘要，内容不能伪造另一条文件边界。准备时复验相同快照，再写入按完整摘要寻址的内容目录。清单中的 repository 只是作者声明，系统身份来自经核验的分发目录项；不接受用户路径或临时扫描令牌新增资源。

默认软件目录来自 [独立插件仓库的 HTTP Release 清单](https://github.com/JieWaZi/neux-plugins/releases/latest/download/catalog.json)。目录检索只读取有界元数据；完整清单及 HTTP 校验信息按来源隔离，原子保存到应用数据目录的 `plugins/catalog/`。每次 Core 启动后后台同步一次；用户可通过“检查更新”显式重新核验同一来源，合并并发请求。有缓存时普通查询立即返回旧快照，搜索、分页、窗口恢复及页面切换不触发额外远端下载。支持 ETag 与 Last-Modified 条件请求，304 复用原内容；同步完成后通过既有插件事件刷新目录查询。当前详情及安装准备遇到已失效的归档地址或内容摘要时，允许一次按原可信来源刷新目录并重解析当前条目，合并并发恢复后只重试新归档一次，不增加轮询。绑定具体提交和摘要的原文与技能请求不静默换成新版本。来源不可用或响应损坏时保留旧缓存并显示 stale、时间及稳定错误；目录和归档获取失败按分发错误表达，不复用配置、认证与程序就绪提示。首次无缓存的并发查询合并等待同一次同步，失败不伪装成零条目。同步使用 Core 取消边界，退出时取消并等待请求结束。`ALLY_PLUGIN_CATALOG_URL` 可明确指定 HTTP 镜像或本地目录；旧应用资源目录不覆盖默认在线来源。安装按同一目录项的 sourceCommit、archiveURL、archiveSHA256 和 packagePath 下载并校验 ZIP，半包或摘要错误不发布。运行期间没有 Git 可执行文件依赖，应用构建不携带插件安装 ZIP。

ZIP 解开后保存完整来源根，自有插件直接包含实际能力。包内引用始终限于同一不可变快照，路径穿越和访问包外内容被拒绝。原包身份与派生目标的名称、版本、摘要及组成分别保留。

目录详情、README 和 SKILL.md 优先读取发布时生成的独立公开资料文件，不要求安装、配置、认证或授权程序就绪，也不下载完整安装 ZIP。目录项通过 `detailsURL`、`detailsSHA256`、`detailsSize` 声明资料，三项必须完整；资料最多 4 MiB，并绑定同一 `sourceCommit`、`archiveSHA256` 和 `packagePath`。资料只包含公开元数据、本地图标、双语 README、技能说明及连接器公开地址，不包含命令、参数、环境变量、请求头或秘密绑定。客户端校验摘要、大小、协议及来源绑定后按内容摘要缓存，并合并并发下载；已声明资料损坏或不可用时准确报错，不隐式下载 ZIP。旧目录未声明资料时兼容原有归档读取。安装准备始终下载并复验完整 ZIP，从真实包重新解析执行能力，不能将公开资料作为安装或执行依据。目录技能通过资料只读展示 SKILL.md，其他资源需从实际安装内容读取。

独立仓库在 `plugins/<name>/` 下自行维护一套完整 OpenAI/Codex 标准包，可以参考官方开源示例封装，并按许可保留实际复用内容、来源和修改记录。认证授权由包内桥接定制，宿主复用通用协议；不分别维护 Codex、Claude 两份来源或空引用入口。发布构建从本仓库固定快照生成完整 ZIP，不依赖临时获取上游插件内容。原生目标配置从实际清单推导，执行只校验并交付当前目标所需的配置。供应商凭据沿受保护配置保存，不进入公共结果。

业务插件、专用授权流程、程序依赖、来源锁与发布归独立 neux-plugins 仓库维护。宿主只负责通用目录、完整性校验、版本安装、配置、授权桥接与 Runtime 交付，不内置供应商 CLI 或维护供应商授权分支。插件包保留各自第三方许可与 provenance，见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。

公开说明来自逻辑插件自身的业务 README，中文使用 `README.zh-CN.md`，英文使用 `README.md`，缺中文文件时回退英文；仅介绍插件能力、权限前提和使用示例，不写伙伴、宿主安装入口或聊天引导；维护与适配细节进入开发文档和声明。图标由标准 `interface.logo` 声明包内资产；附加展示文件只维护中英名称与简介映射，目录同时返回经校验的小图标和语言资料，安装前无需下载完整归档即可显示。用户自定义名称优先于默认本地化名称。正文与原文查询的缓存身份包含语言，避免切换语言或版本后串内容。

## 安装与卸载

未安装插件点击条目直接进入详情页。点击安装后展示 NeuxBot 与插件图标，先选择一个或多个伙伴，再处理必要配置与共享认证。当前会话明确返回二维码、外链或验证码动作时，安装面板显示对应交互；普通 URL 不自动生成二维码。支持二维码的挑战优先内联显示；生成期间展示同位置加载状态，提供刷新图标，刷新等待旧会话取消后再发起，不提供重复显示按钮。授权信息简短说明共享范围，等待不误报缺权限，完成阶段通过既有事件更新，真实账号核验通过后才为所选伙伴安装。准备、授权和数据库安装关系分别处理；取消选择不会产生占位关系，也不会清除已完成的共享认证。批量安装逐伙伴返回结果，重复安装保留原版本与启停。

安装授权弹窗在首次状态或授权动作尚未返回时保留交互区域并显示加载提示，外链和验证码也遵循同一等待状态。二维码或授权码居中展示，加载说明、刷新及验证码说明放在展示区域下方，“打开授权页面”使用底部撑满内容宽度的绿色按钮，布局不依赖桥接动作的返回顺序。安装弹窗不展示“重新授权”和“取消本次认证”按钮；关闭、Escape、遮罩关闭或卸载组件时取消本弹窗仍在等待的会话，启动响应晚到也须补偿取消。已完成认证和自动安装成功关闭不撤销共享账号；重新授权保留在编辑入口。二维码刷新仍先结束旧会话再启动新会话。

普通设置更新验证所有保留安装使用的版本。内容继续按完整摘要保存不可变版本，准备不会改变伙伴安装，相同版本号不能覆盖不同内容。“插件库”展示当前目录发布版本；“我的插件”和伙伴详情读取实际安装的固定版本，准备但尚未安装的新版本不能替换其内容。全局存在多个安装版本时，概览仍从真实安装中选择，具体伙伴始终读取自身版本。第三方插件显示官方来源版本，自有插件使用自身版本。官方远程服务显示“官方托管”，不将内部包装版本当作远端部署版本。

伙伴卸载全局资源保留其他伙伴关系；整体删除先确认实际影响集合。卸载同一插件的最后一个实际安装时，先取消未完成授权、等待包内桥接进程退出并清理其本机共享授权，再删除关系；删除没有安装的资源也会检查该插件是否仍被其他伙伴使用，避免保留孤立授权。关闭的安装仍属于保留引用。清理期间阻止新安装和新执行取得身份，已有工作占用会阻止最后引用删除；其他伙伴仍有安装时不清理共享账号。桥接清理在数据库事务外执行，清理失败保留原关系供重试，准备或首次安装不自动清除已经完成的授权。内容与 PLUGIN_DATA 在数据库引用和活跃执行占用均消失后回收。准备、接纳与回收由同一进程内内容边界协调，回收不穿过受管子目录链接。

## 执行与连续对话

Codex 与 Claude 的原生配置根和其 `worktrees` 下的独立工作区分别校验。工作区内的受管模型账号、隔离运行目录和聊天能力摘要不能仅因嵌套在原生配置根下被拒绝；摘要仍限定为当前工作区的固定私有路径或本次隔离账号目录。全局配置根、插件缓存、`worktrees` 集合根以及中间符号链接不属于该工作区边界，不能通过目录嵌套取得共享原生状态的写入权限。

Execution 在接纳时读取同一事务中的自有插件资源、版本、安装和配置，复验摘要后按目标生成原生包或 Skill/MCP。第三方原生插件使用各 CLI 的原生安装环境，安装、启停、认证与卸载由 CLI 管理；NeuxBot 不将其同步为资源、伙伴关系、技能或连接器。自有插件以执行级原生配置附加，不覆盖外部全局安装关系。共享原生插件配置与所选模型账号分别处理，不能以共享插件为由覆盖外部模型账号；受限执行继续核验可交付范围，不能自动取得外部整包。

原生模型账号与 API 账号直接使用对应 CLI 的原生配置根。Codex API 模型配置通过进程参数和私有环境变量覆盖；Claude API 模型配置通过本轮 `--settings` 读取，原生插件注册与认证仍使用共享目录，不改写外部模型账号。Codex 订阅账号保留既有隔离模型目录，连接共享插件视图；文件型 MCP OAuth 凭据与不绑定 home 的 Direct 钥匙串可共享，绑定 home 的 Secrets 后端与隔离订阅账号组合准确拒绝，包括首次授权，不能创建一份外部不可见的新身份。隔离订阅分支按 Codex 实际顺序先处理配置覆盖，再应用 enable、disable；遇到 profile、无法完整解释的覆盖或本机管理配置层时同样拒绝，避免把认证写入错误身份。上述组合需改用原生 CLI 账号或 API 模型账号；未承诺不可观察的企业云策略层兼容。

原生快照变化时后续普通会话重建并复用既有有界历史；不把旧线程句柄传给新的配置根。执行接纳事实冻结外部原生插件摘要，分叉沿既有冻结配置继承该摘要和自有插件快照；首次续聊以这些权威事实核验当前能力，不依赖新工作区尚未建立的摘要缓存。已分支会话的摘要未知或能力发生变化时准确拒绝，不能重新注入继承历史。相同快照复用已核验的派生产物，缓存被篡改时拒绝，不原地改写其他活跃执行正在读取的包。原生 CLI 自身的用户级默认技能发现与受管插件身份分别存在，私有 CODEX_HOME 本身不宣称隔离所有用户级技能。

自动按需能力来自伙伴实际启用的自有插件；本轮明确引用通过 pluginIds 单独提交，并只附加本轮选择提示。系统安装只通过插件库界面执行。`allycli capabilities` 不再公开系统插件搜索、详情、安装与安装状态操作，系统 Skill 也不再要求聊天安装经过 allycli。聊天中的原生安装由当前 CLI 自己执行并落入与外部相同 CLI 共用的原生插件环境，不创建系统安装关系。

STDIO 配置经过 Core 的无协议转换启动模式设置 cwd，保持原始 argv、env 与三个标准流；没有 shell 字符串拼接。MCP 传输依当前智能体探测能力交付，派生服务使用稳定组件授权身份并继续接受现有 MCP 白名单限制。受限入口只交付明确获准的组件；MCP 白名单不授予包内技能的命令执行能力，也不构成 shell 沙箱。

消息保存明确选择的插件展示快照，执行保存实际交付插件的版本、配置修订、提供者身份及组件身份，不保存凭据。重试必须满足原版本、配置修订、身份、组件集合、实际目标摘要与交付方式，无法恢复时明确失败。原生会话挂载和进程环境继续由 Runtime SDK 管理，提供者身份变化参与环境指纹。

## 发现新版与统一更新

更新状态由当前可信目录快照与实际伙伴安装派生，不建立独立更新表。目录条目必须精确匹配资源来源，只有包的有效语义版本高于实际安装版本才提示“可更新”；同版本、目录回退或未知版本不自动当作升级。包的比较版本用于校验与固定目标，用户展示资料继续使用明确的业务上游版本，不把辅助程序版本作为业务服务版本。普通本机列表与详情只读取已缓存目录和安装，不等待网络、不下载归档；目录尚未就绪或失效时保留安装内容，明确表达未核验或陈旧，不能声称已是最新。

“我的插件”卡片右上角提供“可更新”入口，详情提供更新操作。资源列表在搜索框前展示 Info 图标，悬停不增加灰色背景；悬停、聚焦或点击后在交互浮层中显示上次成功检查时间与刷新图标按钮，尚未核验时明确说明。刷新点击即检查更新，处理中禁用；浮层允许指针移入点击及键盘操作。输入框后不单独放刷新按钮，检查时间不占用额外常驻行。检查使用现有条件请求与来源缓存，成功和失败均经插件资源事件对账，没有常驻轮询。检查只刷新目录，不准备内容，也不改变伙伴关系。

一次更新覆盖该插件全部已安装伙伴，不提供选择伙伴的控件。更新弹窗说明影响范围，先核对确认的目录归档摘要、准备不可变目标，再处理目标版本要求的共享配置和真实授权。目录在此期间变化、摘要不符、信任未确认或授权失败均不能静默改用其他目标。准备成功不等于完成更新，也不能提前替换“我的插件”的安装展示。

最终提交复用共享配置与版本切换事务，完整比对确认时的安装集合、每个伙伴原版本和配置修订，并要求全部切换至同一目标。确认后新增安装、卸载或改版时整次拒绝，刷新后由用户重试，不把旧集合当作全部伙伴。全部伙伴的原启停状态保持；任一检查失败时配置和安装一并回滚。已接纳工作继续使用原先冻结的版本、配置与身份，后续工作才使用新版本。部分历史版本、共享配置和身份占用继续遵守原有内容与授权边界。

## 共享认证

普通插件列表与详情只读取数据库中的版本、安装和配置快照，并从现有授权管理器读取当前 Core 内最近一次真实核验的公开身份摘要；不创建或替换授权桥接、不启动供应商程序，也不遍历完整包。摘要携带 `checkedAt`；Core 重启、配置或桥接版本切换后，未核验的身份保持未确认，不能据此提示授权已失效。退出成功记录明确不可用的摘要，核验失败清除旧的可用摘要；身份重置前发起的迟到查询不能恢复旧摘要。该摘要仅服务展示，不保存凭据，也不能作为安装或执行准入依据。授权操作、安装、版本切换和执行接纳继续校验固定内容及真实身份；既有授权完成和安装等资源事件负责刷新展示，不增加状态轮询。聊天引用按实际安装和启停关系展示固定版本，不因未确认授权隐藏引用，真实可用性由执行接纳核验。普通详情仅按固定文件名有界读取对应语言的 README；短读与内容回收共用互斥边界，释放时不触发全库垃圾回收。组件直接采用已保存快照，不通过重新扫描补齐旧版本元数据；原文下载与技能文件读取仍保留各自的固定内容校验。

`internal/plugins/authorization` 统一管理会话、Core 生命周期、取消、工作占用和安全摘要。插件在 `.neuxally/integration.json` 声明 `plugin-command` 与 `neuxally-auth/1`，通过可选 `preferredAction` 指定加载偏好，通过 `bindings` 精确限定目标、MCP 键、HTTPS 地址和请求头，宿主用固定包内入口及独立 argv 启动，供应商 CLI 和扫码解析归包内桥接。宿主只理解 auth/start、status、cancel、resolve、logout 的逐行 JSON-RPC 和绑定当前会话的 challenge/state 通知；URL、二维码、验证码按本次 actions 渲染，不按插件名称判断。auth/start 首次挑战前允许 150 秒准备受管资产与启动进程，status、resolve、logout 等普通请求仍限 30 秒；收到挑战后改用其实际期限。deadlineAt 与官方 expiresAt 分别表达本机等待和上游期限，取消在准备和扫码阶段均立即传递并等待真实进程退出，终态清除临时挑战。 `show-qr.value` 的普通字符串作为二维码原始载荷编码；严格的 `data:image/png;base64,...` 则直接展示官方 PNG 原图，宿主限制解码后不超过 256 KiB、宽高各不超过 1024 像素，并完整解码、拒绝尾随数据。SVG、其他 MIME、非标准 Base64 以及损坏或超限图片均被拒绝；远端 URL 继续作为扫码载荷编码，不作为远端图片加载。

授权挑战可声明 `notice.messages` 阶段提示，使用 `en`、`zh-CN` 语言键，每条最多 2 KiB。前端按界面语言选择纯文本，缺中文时回退英文，以统一黄色提示卡展示；没有声明则不展示。提示只属于当前等待挑战，后续挑战未声明时移除，取消或终态一并清除。飞书包在自身授权展示文件声明首次设置后的二次扫码说明，并仅在应用设置挑战发送；宿主不根据插件名称、URL 或账号字段猜测提示内容和阶段。

桥接 resolve 只接受本轮获准的稳定组件身份，秘密绑定不进入 HTTP 公共结果、聊天、日志或索引，不能修改已核准端点或 Runtime 身份。PATH 只能由插件私有已核验目录和宿主原有受信路径组成。多个技能 CLI 的 PATH 按接纳顺序合并去重，私有程序目录统一位于继承路径之前，避免系统同名程序覆盖后接纳插件；其他同名环境变量的值不一致时仍拒绝执行。STDIO MCP 的环境绑定只交付对应连接器，不合入技能共享环境。不同插件按资源身份隔离私有数据与账号；同一插件所有伙伴共用身份租约。桥接指纹包含完整内容摘要及实际包路径，版本只能在无授权等待和执行占用时更换；旧桥接与新桥接不能同时绕过同一共享身份边界。绑定可以作用于同一自有标准包，也可用于自有包支持的明确目标；有明确绑定而当前目标未匹配时不能借用旧版无绑定流程。当前 GitHub 包只声明 Codex、Claude 两个授权目标，不代表所有 Skill/MCP 目标都能取得其凭据。原生派生只写无秘密模板，Codex 使用 `env_http_headers`，Claude 使用 `headers` 的环境引用；真实凭据仅进入私有执行环境，诊断日志按当前秘密值脱敏。未绑定头与其他配置仍正常校验，托管 apps 的独立授权保持其自身边界。宿主明确拒绝旧供应商 provider 声明，授权与依赖准备由当前标准插件包通过同一协议完成。

包内授权程序、MCP 和其他原生执行组件均纳入受管预检的执行确认，目录准备结果返回权威 `trustRequired`。未确认版本不能启动授权桥接，包括直接授权接口。桥接取消先发协议请求并给上游停止窗口，随后回收受管进程组及关闭读取，避免子进程持有 stdout 造成永久等待。

## 接口与前端

插件接口在 `server/apis/plugins`，独立技能与连接器通过各自全局 LibraryRouter 和伙伴操作复用同一用例。完整 HTTP 契约由 [OpenAPI](../../server/openapi.json) 生成前端 Client；不手工维护第二份协议声明。

资源库以三个可键盘切换的分类入口组织插件、技能和连接器，下方共用紧凑图标条目和按内容容器降列的三列网格。资源页 Toolbar 统一行高与分割线位置；插件提供文字加底部指示线的“插件库 / 我的插件”切换，后接当前结果的资源数量，技能与连接器使用分类标题与来源筛选。插件库保持图标、标题、单行简介与“+”入口。只有当前存在实际安装且共享身份明确不可用时才显示“授权”；任一伙伴完成共享授权后恢复“+”，不根据提供者类别直接判定需要授权。安装与授权成功使用绿色状态提示，与授权中的黄色说明复用同一提示容器。安装弹窗先关联目录对应的真实本机资源，再读取详情接口；伙伴选择器展示真实静态头像，已安装关系勾选并禁用。重新授权复用已有安装，不重复安装伙伴。我的插件复用普通资源 Card，存在新版时在右上角展示可点击的“可更新”，底栏提供实际伙伴使用数和更多操作菜单，不增加分隔线，不重复展示已授权、开发者与版本。独立技能和连接器的添加操作位于标题右侧；插件仅通过插件库条目安装，不提供上传或导入操作。伙伴资源页不重复提供列表内安装按钮。技能与连接器支持“全部来源、来自插件、独立安装”筛选，默认按独立安装、来自插件的顺序各预览最多九项；分组有数据时才显示完整计数与筛选箭头，筛选后不重复显示来源标题。插件列表与筛选后的卡片列表首批显示九项，后续按滚动追加，不提供翻页控件。插件、技能与连接器列表保留数量、选择与批量删除入口，技能与连接器保留分类标题；插件删除确认以图标、名称和伙伴使用数列出目标，并说明共享配置、伙伴安装关系和不再使用的本机授权信息的清理范围。内置资源和包内能力不作为独立删除目标；包内能力通过所属插件管理。包内能力直接读取插件快照，伙伴页只展示其实际安装版本，关闭或未就绪的插件能力仍可查看，启停和配置由所属插件统一管理；预检显示来源格式、开发者、版本、许可、组成和兼容性诊断，含 MCP、原生执行组件或授权程序的包按预检结果确认执行内容。URL 保存分类、视图、搜索与来源筛选。目录插件和已保存插件均使用详情页展示简介、可点击查看完整 SKILL.md 的技能、连接器、已安装伙伴及开发者、版本、许可和公开政策链接；技能按业务名称、连接器按业务键统一去重，系统内部确定正文来源，不展示 CLI 标签或实现版本；没有技能或连接器时隐藏对应区块；已安装伙伴的名称与真实头像从同一批伙伴记录补齐；没有头像资料时显示中性占位，不按名称推导新的伙伴形象。三种插件详情的信息层级与编辑入口遵守 [UI 标准](../development/ui-cn.md)。说明优先展示面向用户的 Markdown 能力说明。说明与简介来自当前入口版本的原始 README
