# 伙伴资源与记忆

## 伙伴与项目

创建伙伴时保存名称、头像、简介和可选默认模型。Core 通过普通 Chat 和 Execution 发起建档对话，依据该伙伴的默认模型或全局默认配置启动首轮。普通新聊天采用伙伴默认模型，已有聊天恢复自己的执行选择。

伙伴详情在编辑操作之后提供独立默认模型选择入口，直接选择并保存模型或恢复跟随全局默认。模型更新只写入该执行配置；基本资料弹窗按内容自适应高度，只编辑名称、角色名称、头像和简介。

建档对话由伙伴生成核心职能、工作风格和工作方式的选项，Core 使用交互问答卡呈现。每题允许多选，也可同时填写「其他」。用户回答后，伙伴结合创建简介和回答生成角色名称、简介及三个展示字段，通过本轮授权的 botcli 和英文档案一并提交，Core 在同一事务中保存。伙伴概览预览 `AGENTS.md` 开头，编辑弹窗读取完整正文，Execution 使用同一正文作为伙伴长期指令。

伙伴档案的生成和编辑统一按 `cl100k_base` 校验 1,300 token 正文上限。普通伙伴聊天通过现有执行授权读取和修订该伙伴的档案。档案弹窗的 AI 优化入口在新聊天的输入框预置可移除的「档案优化」标签，沿用普通聊天的智能体配置和能力；标签保留时仅为首条消息附加修改意图，移除后按普通聊天发送。智能体按需读取档案和版本，依据用户要求提交正文、核心职能、工作风格和工作方式的变化。Core 在同一事务中检查档案版本、保存变更与回执，省略的字段沿用当前值。三个展示字段由建档或 AI 优化维护，伙伴基本资料编辑不提供这些字段的写入入口。直接编辑 Markdown 只保存正文，使用打开编辑器时的正文版本，保存冲突会保留草稿；涉及展示内容的修改通过 AI 优化一并提交。提交后的伙伴实体与资源事件分别刷新展示资料和档案正文。

系统启动时幂等补建私人助理 lumi。旧伙伴档案按身份、风格和方法的顺序合并，已保存的 `AGENTS.md` 优先。内置伙伴的档案覆盖和已有概览资料随伙伴保存。

复制伙伴在同一事务写入新伙伴资料和解析后的档案，复用请求标识处理重放。聊天、项目、记忆、工作目录和资源安装归属原伙伴。侧栏分组是本地导航偏好。

项目由伙伴拥有，至少包含一个本地目录及一个默认目录。项目删除清理配置，保留真实目录和已冻结聊天；目录可用性在新工作接纳时校验。

## 资源库

插件、技能和连接器聚合在同一入口。全局资源与伙伴安装分别保存；系统插件只从自有插件库安装，包内组件随插件版本派生，外部 CLI 原生插件不进入本资源库。固定目录、共享认证及执行快照见 [插件资源](plugin-resources-cn.md)。

## 技能

技能包具有全局或伙伴范围、资源文件及版本。导入在安装前完整校验路径、内容和批次；全局资源通过明确安装关系对伙伴生效。版本恢复形成新版本，更新不覆盖用户定制。

技能列表在同一读取事务中返回完整安装人数与最多四位实际安装伙伴的名称、头像预览，停用关系仍计入安装。预览按技能批量截取，再批量读取伙伴资料，不逐卡请求，也不以预览数量替代总人数。

学习生成的独立本地技能从来源聊天发布并安装到该伙伴。ZIP 导入和本地学习技能可以生成不可变修订，复用版本对比和回滚。共享技能的新版本会影响所有安装者，发布前由来源聊天提示受影响的伙伴并确认。

Runtime 在受管工作区交付当前技能与原生指令，不向项目真实源码写入应用配置。系统技能单独随应用构建，不依赖普通技能启停关系。可选技能投影损坏时，宿主隔离受影响的发现路径，保留原文件供恢复。共享快照仍被其他发现目录引用时，隔离限于当前目录。

本地工作台聊天可以明确要求新建、修订、卸载或删除技能。通过 NeuxBot 工具提交完整 `SKILL.md`，修订按读到的版本发布并保留已有附件。卸载只解除当前伙伴的安装关系。删除本地库资源及其版本时，Core 确认受影响的伙伴。提交后的回执写入原会话时间线，新建和修订可打开资源库的技能详情。

## MCP 连接器

本地工作台聊天可为当前伙伴添加 MCP 连接器、更新配置、测试连接、解除共享关系或删除连接器。Core 复用资源库的验证、信任和保存流程，核对版本与批准的影响范围。聊天新建的连接器经用户确认后测试，保存到资源库并安装给当前伙伴。测试通过即启用，失败则保留停用的配置供编辑。影响已启用连接的配置更新须通过连接检查。读回配置时隐藏凭据，密钥通过 NeuxBot 设置录入。提交后的回执写入原会话时间线，添加和更新可打开资源库的连接器详情，伙伴自有连接器使用原归属读取和管理。

连接器具有全局或伙伴归属，资源库展示全部独立连接器，伙伴自有资源的详情按所属伙伴读取。全局资源可安装给其他伙伴。共享配置与伙伴安装、启用关系分别存储。普通聊天可在原会话继续使用已启用的技能和连接器，后续发送时读取新的资源配置。STDIO、Streamable HTTP 和 SSE 按 Runtime 真实能力交付；连接测试由 Core MCP 客户端执行，不需要模型调用。

敏感环境值和请求头由 Controller 加密保存，查询只返回是否配置。当前密钥与密文同库，该机制不能替代设备访问安全边界。编辑空值保留已有凭据，显式清除由独立操作表达。

首次执行或配置变化按现有信任契约确认完整命令、逐项参数或远程目标。聊天更新已验证的配置时随本次更新保存对应的测试结果和工具。直接编辑配置使原测试结果失效。

聊天资源变更在领域事务中保存原命令回执。聊天按同一回执幂等写入时间线，启动或读历史时补写待确认的变更。

## 记忆

长期记忆归伙伴所有。记忆页面和 `botcli memory entries` 按伙伴读取、创建、更新及遗忘条目。botcli 从已授权执行取得伙伴身份。

`memory.db` 使用独立 SQLite、FTS5 和 sqlite-vec 保存内容、历史及索引。相同内容按伙伴精确去重。配置 Embedding 且索引就绪时执行语义搜索，其余情况使用关键词检索并报告实际模式。模型和维度指纹用于校验向量一致性。

核心记忆以 8 KiB 为伙伴快照的序列化预算，在普通伙伴工作台聊天中通过统一的本轮事实块交付，作为模型参考数据。每个原生绑定在快照变化或交付状态未知时接收最新版本。普通记忆按需检索。分类或正文变化与快照更新在同一事务提交。

## 记忆与学习

「设置 → 智能体 → 记忆与学习」统一配置使用的智能体和整理频率。默认跟随伙伴新对话的智能体、账号和模型，也可全局指定。「配置伙伴」列出各伙伴的自动记忆及技能学习开关，技能学习开启后可选择先询问或自动保存。两项默认关闭。语义检索在本页展开配置。实际配置不可用或后台处理失败时，在对应伙伴详情中提示并提供重试。

普通工作台聊天的成功轮次触发后台复盘。默认每 20 轮，可选 5、10、20、30、50 轮。至少完成 3 个合格轮次且空闲 15 分钟也可触发。每个 Chat 共用持久进度，按轮次接纳时的功能授权选择有界证据，只发送本批启用功能的规则和候选。项目对话参与已启用的技能学习。已有记忆候选来自同伙伴的核心记忆、本地关键词命中及近期普通记忆。自动记忆可新增、更新和遗忘，提交时复核消息证据与条目修订。

复盘和技能生成各自在开始时选择当前模型。设置变更从后续执行生效，正在运行的复盘照常提交，切换模型后继续使用已有的合格轮次。Embedding 配置在生成向量后变化时先保存正文和关键词索引，语义索引沿用现有重建流程。技能证据使用公开最终答复和单独的结构化工具步骤。

手工创建或编辑的条目持续受用户保护。自动生成的条目手动设为核心时受保护，改回普通后恢复自动更新和遗忘。

技能学习先提出短建议。询问模式经来源聊天确认后生成和发布，自动模式在符合权限时继续生成。设置变更后，已生成的建议仍可在来源聊天处理，已排队的发布继续执行。技能版本、安装关系与唯一发布回执一起提交。重复保存返回相同版本。删除来源聊天或伙伴时，作废未发布的结果。

复盘和技能生成使用现有的独立文本调用，每次新建一轮会话。Core 不挂载应用工具或伙伴工作区，不批准工具请求，按智能体应用已有的原生限制。Claude 可关闭原生会话持久化。Codex 必须确认原生临时线程后才接收复盘正文。其他 CLI 的本地留存取决于原生适配器。Core 的持久原生流只保存调用身份和用量终态元数据。启动时回收复盘所属的临时目录。候选、游标和已保存的资源按各自领域保存。模型证据、引用及提示规则见[模型指令与消息组装](../development/model-input-cn.md#历史核心记忆和复盘引用)。
