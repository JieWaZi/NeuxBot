# 聊天与工作台

在伙伴侧栏点「新建伙伴」，选择头像、填写名称和概要，并按需绑定默认模型。创建后直接进入对话，每道交互题可以选多个伙伴提供的选项，也可同时选「其他」补充。回答后，伙伴会自动生成角色名称、简介、核心职能、工作风格和工作方式，并保存精简的英文档案。概览右侧的「伙伴档案」在技能与连接器下方显示正文预览，点击编辑可在弹窗中修改完整档案。角色名称和简介可在伙伴资料中修改。

编辑档案时可点「AI 优化」，在打开的伙伴对话里说明修改要求。也可以直接在普通伙伴对话里要求修改。伙伴会按要求更新档案正文、核心职能、工作风格和工作方式中的相关内容。档案正文的保存上限为 1,300 token（按 `cl100k_base` 计数）。

右键点击侧栏伙伴可标为未读、移动到分组、编辑、复制或删除。标为未读应用于最近公开对话，保留已有未读范围。分组随本地侧栏偏好保存。复制会新建独立伙伴，带上基础资料、默认模型及档案。删除需要输入伙伴名称确认。

项目将一个或多个真实本地目录组织在伙伴名下。也可以直接选择临时文件夹或使用应用受管目录。

## 对话

发送前检查智能体、账号、模型、权限和目录。首次接纳后固定工作范围，续聊沿用同一聊天身份。实时过程展示说明、思考及工具活动，最终结果和失败保留在消息中。

在普通伙伴私聊和项目对话中，点自己已发送的文字消息或伙伴已结束的文字答复旁的回复图标。输入框上方会显示原消息摘要，点 × 可取消引用。发送后，正文上方显示最多三行引用摘要，引用自己的消息时标注「你」。激活引用会把原消息滚动到视区中央，并短暂强调原消息气泡。用键盘激活时，焦点会移到原消息。

在团队主对话中，也可以展开并回复成员报告。回复发给负责人，由负责人决定是否委派。进入成员自己的对话后，回复发给当前成员。引用团队伙伴的消息时会显示该伙伴的名称。

运行中输入根据能力即时送达或进入临时队列。队列内容未接纳前仍属于待发送输入。停止当前执行后可继续阅读和处理后续工作；重试入口只在服务端判定安全时提供。

## 工作台

Diff、文件、浏览器和终端通过工作台标签打开，可分屏并保留各自内容。从项目文件树、聊天引用或 Diff 打开同一个项目文件时，会定位到同一文件标签。文件树跟随当前文件滚动到选中项，可搜索、刷新或收起。聊天引用带有行号时会打开源码并定位到对应行。文件使用原聊天权限和真实路径，切换伙伴或团队成员不改变已打开文件的来源身份。

文件类型按能力提供代码、预览、编辑或下载。HTML 默认代码，Markdown 默认预览；未知或未确认路径保持原文，不假装成可用文件。关闭终端结束该终端会话。

从会话摘要选择仓库，可新建或切换分支、查看改动、提交、推送和创建 GitHub PR。点「改动」打开 Diff。分支比较查看相对所选基准的净变更，「未提交」查看 HEAD 到工作树的净变更，「提交历史」查看当前分支相对基准的提交。在「暂存与工作区」中可以暂存、取消暂存或放弃未暂存改动。

提交弹窗允许直接勾选工作区文件。已有暂存内容时默认提交暂存区，也可以切换到选文件。选文件模式提交这些文件在工作区中的当前内容。消息留空会根据本次提交内容自动生成。推送沿用本机 Git 凭据，GitHub PR 使用本机 `gh`。组合动作中途失败时，已完成的提交或推送会显示在原仓库下。

摘要也可定位上传和生成文件以及团队成员。摘要预览有数量上限，完整列表通过相应入口读取。结果阅读、审批与提示关闭分别操作。
