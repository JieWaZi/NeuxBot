# 聊天与工作台

在伙伴侧栏点「新建伙伴」，选择头像、填写名称和概要，并按需绑定默认模型。创建成功后直接进入该伙伴的主会话。建档工作有自己的提问记录，每道建档题可以选多个伙伴提供的选项，也可同时选「其他」补充。回答后，伙伴会自动生成角色名称、简介、核心职能、工作风格和工作方式，并保存精简的英文档案。概览右侧的「伙伴档案」在技能与连接器下方显示正文预览，点击编辑可在弹窗中修改完整档案。角色名称和简介可在伙伴资料中修改。

编辑档案时可点「AI 优化」，在打开的伙伴对话里说明修改要求。也可以直接在普通伙伴对话里要求修改。伙伴会按要求更新档案正文、核心职能、工作风格和工作方式中的相关内容。档案正文的保存上限为 1,300 token（按 `cl100k_base` 计数）。

右键点击侧栏伙伴可标为未读、移动到分组、编辑、复制或删除。标为未读优先应用于伙伴主会话，保留已有未读范围。如果主会话还没有伙伴的公开发言，则应用于最近的普通公开对话。同组内拖拽可调整顺序，跨组拖拽会移动伙伴并保留落点。同一 Core 的客户端共用伙伴分组和排列顺序。首次升级时，已有本机分组和排序可导入尚无导航布局的 Core。

复制会在原分组紧跟原伙伴新建副本，带上基础资料、默认模型、档案、当前记忆、空间文件和已安装技能的启停状态。副本从空对话开始，已有对话和外部项目继续归原伙伴使用。伙伴正在执行工作时，等本次工作结束后即可复制。删除需要输入伙伴名称确认。

项目将一个或多个真实本地目录组织在伙伴名下。也可以直接选择临时文件夹或使用应用受管目录。

## 主会话

点侧栏的伙伴或团队即可回到该主体的主会话。伙伴聊天顶栏的第一个页签显示伙伴头像和名称，随时可以点它回主会话。右侧「＋」打开这个伙伴的普通对话草稿，发送第一条消息后建立聊天。伙伴可以先发一条需要你处理的发现，查清原因后再发一条结论。点某一条旁的回复图标，就能单独追问。主会话和工作记录都使用紧凑输入框，附件、权限、模型和发送操作集中在底部一行。回复来自某个项目的消息时，伙伴沿用那条消息的工作范围。

伙伴使用工具检查文件后，明确给出的最终答复也会回到主会话。若主会话只留下交办，可在气泡左侧的「⋯」菜单中选择「查看工作记录」。回复按钮和菜单并排显示。用户和伙伴的消息都可以从菜单复制或删除。删除只从主会话移除选中的消息，执行过程仍保存在工作记录中。伙伴的公开发言还可以从这里分支或标记未读，分支沿用原工作回合和运行时支持范围。

从主会话或工作记录发送失败时，输入框上方会用红色显示原因。点击右侧「重试原发送」即可在当前窗口重试，同一条交办只接纳一次。若 Codex 明确报告原运行会话找不到历史，伙伴会在原工作记录内尝试新建一次运行会话，带上近期已完成的对话，再发送本条消息。

如果提示无法新建或恢复运行会话，且可以确认这条消息尚未接纳，可点「返回编辑」保留草稿，调整模型或账号后再发。若断网或发送结果仍待确认，请恢复连接后使用「重试原发送」，以原提交标识核对结果。

侧栏伙伴或团队的未读角标对应其主会话。在工作看板的「待我查看」可打开主会话或独立会话的未读结果。窗口在前台且主会话发言进入视区后，未读数会随阅读位置更新，其他窗口也会同步。

当原话和答复之间还有其他消息时，伙伴可在答复中加上引用。点击引用可以回到原话。主会话会按需加载历史，将原话滚动到视区中央并短暂高亮。原话特别久远时，可点「继续定位」再往前查。读取失败可以在引用处重试。如果原话已不可访问，引用处会提示「原消息不可用」。

发送消息后，消息区显示「正在等待回复」，侧栏伙伴头像在输入进入队列后显示工作状态。首条答复到达后，头像和名称显示在该组发言的第一条旁。常规问答和未指定项目的工作沿用伙伴的固定来源会话。点击这些发言的头像能打开同一份多轮记录，查看执行过程和 CLI 的完整答复。来自主会话的提问可点回原话。在工作记录里继续提问时，输入留在当前会话，需要同步的结果可以发回主会话。独立工作记录沿用其原目录。

在伙伴工作记录里选用同一运行时及账号下的另一个模型时，时间线会记录这次选择。选择用于后续发送，已接纳的回合继续使用原配置。

在伙伴主会话或工作记录里更换智能体或账号时，可以选「最近对话」或「自动总结」接续已有工作。最近对话默认带上 5 个完整轮次。自动总结由原智能体整理，无法整理时使用所选的最近轮数。主会话内引用消息时，接力沿用该消息的原工作。取消切换会保留草稿。

伙伴需要你回答或授权时，主会话会显示对应的卡片。你可以当场回答，也可以在工作记录或工作看板的「需要处理」中打开同一请求。提交后原工作继续。已结算的提问保留在原交办下方，也可在工作记录里回看。用窗口顶栏的后退箭头回到主会话，草稿和阅读位置会保留。前进箭头可再次进入刚才的工作记录。

主会话和工作记录右上角都可以打开「查看摘要」，旁边的「工作区」可以展开或收起右侧工作台。主会话摘要的「任务」只列由该主会话启动且正在执行的任务。每行显示实际运行的 CLI 图标和工作会话名称。点击名称可以打开对应工作会话。

在桌面端，点击主会话或工作记录正文中的网页链接，右侧会打开浏览器页签，可以一边看网页一边继续聊天。主会话的会话文件来自已经载入的公开消息。进入某项工作后，摘要显示该工作的文件与可用项目目录。点击附件或代码引用时使用它所属的工作范围。正文里的本地图片沿用聊天的缩略图和放大预览。

## 普通对话

发送前检查智能体、账号、模型、权限和目录。首次接纳后固定工作范围，续聊沿用同一聊天身份。实时过程展示说明、思考及工具活动，最终结果和失败保留在消息中。

在普通伙伴私聊和项目对话中，点自己已发送的文字消息或伙伴已结束的文字答复旁的回复图标。输入框上方会显示原消息摘要，点 × 可取消引用。发送后，正文上方显示最多三行引用摘要，引用自己的消息时标注「你」。激活引用会把原消息滚动到视区中央，并短暂强调原消息气泡。用键盘激活时，焦点会移到原消息。

在团队线程的负责人对话中，也可以展开并回复成员报告。回复发给负责人，由负责人决定是否委派。进入成员自己的对话后，回复发给当前成员。引用团队伙伴的消息时会显示该伙伴的名称。

运行中输入根据能力即时送达或进入临时队列。队列内容未接纳前仍属于待发送输入。停止当前执行后可继续阅读和处理后续工作；重试入口只在服务端判定安全时提供。

## 长期交办

在伙伴或团队主会话直接发送工作要求，例如「检查示例站点项目里 `README.md` 的失效链接」。伙伴判断需要派工后，会使用它已添加的项目，或你在这次请求中明确指定的绝对目录。项目或目录不明确时，伙伴会先在原会话询问。直接问答由默认会话答复，不创建工作会话。耗时交办接纳后会先说明准备做什么；有多条独立结果时，查实一条发一条。

回复原交办或该单的回报，可以补充材料或继续追问。同一项目中的多个交办各自接收补充和回报。

要把整件事交给另一位伙伴或团队，先引用原交办或回报，再在输入框里发送 `/移交 伙伴或团队全名`。如需补充交接说明，从下一行开始写。随后仍可在原聊天里引用这件事继续沟通，接手人会把结果发回这里。

点回报旁的头像或从原消息菜单打开工作会话，可以定位这项工作的过程和结果。点直接答复旁的头像则打开默认会话。引用原消息可以续办，Core 会核验原授权。回报留在最初交办的会话里。

## 工作台

Diff、文件、浏览器和终端通过工作台标签打开，可分屏。右键页签可关闭其他页签或关闭全部可关闭的页签。目标页签有未保存草稿时，工作台会先确认是否丢弃。

打开「文件」时，右侧直接显示可搜索的目录树，左侧等待选择文件，顶部路径留空。从项目文件树、聊天引用或 Diff 打开同一个项目文件时，会定位到同一文件标签。目录可逐级展开，文件树和搜索结果省略以 `.` 开头的目录及其内容，`.gitignore` 等文件照常显示。点击文件头中的目录可在项目文件树中定位，并保留当前文件。点目录右侧的箭头可浏览子目录或打开文件。文件标签顶部的文件树按钮用于显示或隐藏整棵树。聊天引用带有行号时会打开源码并定位到对应行。文件使用原聊天权限和真实路径，切换伙伴或团队成员不改变已打开文件的来源身份。

项目源码在文件标签内只读预览。桌面可通过文件头的编辑器选择按钮指定本机编辑器，再点击左侧图标打开文件。文件根据类型提供渲染预览，HTML 默认显示代码，Markdown 默认显示预览。未知路径保留原文。关闭终端结束该终端会话。

从会话摘要选择仓库，可新建或切换分支、查看改动、提交、推送和创建 GitHub PR。点「改动」打开 Diff。分支比较查看相对所选基准的净变更，「未提交」查看 HEAD 到工作树的净变更，「提交历史」查看当前分支相对基准的提交。在「暂存与工作区」中可以暂存、取消暂存或放弃未暂存改动。

提交弹窗允许直接勾选工作区文件。已有暂存内容时默认提交暂存区，也可以切换到选文件。选文件模式提交这些文件在工作区中的当前内容。消息留空会根据本次提交内容自动生成。推送沿用本机 Git 凭据，GitHub PR 使用本机 `gh`。组合动作中途失败时，已完成的提交或推送会显示在原仓库下。

摘要也可定位上传和生成文件以及团队成员。摘要预览有数量上限，完整列表通过相应入口读取。结果阅读、审批与提示关闭分别操作。
主会话和工作记录在输入框顶栏显示本次失败的原因。再次发送被接纳后，旧提示会消失，也可以点 × 直接关闭。原交办的「⋯」菜单可打开对应工作记录，处理问题后可以在原处继续发送。
