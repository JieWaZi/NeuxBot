# 聊天与工作台

在伙伴侧栏点「新建伙伴」，选择头像、填写名称和概要，并按需绑定默认模型。创建后直接进入对话，每道交互题可以选多个伙伴提供的选项，也可同时选「其他」补充。回答后，伙伴会自动生成角色名称、简介、核心职能、工作风格和工作方式，并保存精简的英文档案。概览右侧的「伙伴档案」在技能与连接器下方显示正文预览，点击编辑可在弹窗中修改完整档案。角色名称和简介可在伙伴资料中修改。

编辑档案时可点「AI 优化」，在打开的伙伴对话里说明修改要求。也可以直接在普通伙伴对话里要求修改。伙伴会按要求更新档案正文、核心职能、工作风格和工作方式中的相关内容。档案正文的保存上限为 1,300 token（按 `cl100k_base` 计数）。

右键点击侧栏伙伴可标为未读、移动到分组、编辑、复制或删除。标为未读应用于最近公开对话，保留已有未读范围。分组随本地侧栏偏好保存。复制会新建独立伙伴，带上基础资料、默认模型及档案。删除需要输入伙伴名称确认。

项目将一个或多个真实本地目录组织在伙伴名下。也可以直接选择临时文件夹或使用应用受管目录。

## 对话

发送前检查智能体、账号、模型、权限和目录。首次接纳后固定工作范围，续聊沿用同一聊天身份。实时过程展示说明、思考及工具活动，最终结果和失败保留在消息中。

运行中输入根据能力即时送达或进入临时队列。队列内容未接纳前仍属于待发送输入。停止当前执行后可继续阅读和处理后续工作；重试入口只在服务端判定安全时提供。

## 工作台

文件、改动、浏览器和终端通过独立标签打开，可分屏并保留各自内容。文件使用原聊天权限和真实路径，切换伙伴或团队成员不改变已打开文件的来源身份。

文件类型按能力提供代码、预览、编辑或下载。HTML 默认代码，Markdown 默认预览；未知或未确认路径保持原文，不假装成可用文件。关闭终端结束该终端会话。

聊天摘要可定位项目改动、上传与生成文件以及团队成员。摘要预览有数量上限，完整列表通过相应入口读取。结果阅读、审批与提示关闭分别操作。
