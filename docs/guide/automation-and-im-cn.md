# 自动任务与 IM

## 自动任务

选择伙伴、团队或工作流，配置定时或本机 API 触发，并检查目录、智能体、权限和参数。可以启停、立即运行、查看记录或轮换 API 密钥。

工作流参数选择固定值、每次 API 提供或适用默认值。使用详情页生成的当前调用说明，不把密钥放进公开文档。输入文件通过上传入口获取引用，结果从对应运行读取。

定时和本机监听依赖应用、设备及连接状态。关闭窗口可继续托盘运行，退出应用、设备休眠或关机会影响执行；状态以实际运行记录为准。

## IM

连接实际消息平台后，为明确聊天授权伙伴或团队，设置执行范围和必要能力。平台连接、聊天授权和工作状态分别展示。

授权聊天可发起工作并接收结果。文件或工作流交付按当前授权执行，未授权聊天不能仅凭连接存在调用能力。发送失败在交付记录中显示，送达状态与执行结果分别确认。

首次配置、平台登录及群聊行为按当前界面的提示进行；不要在 Issue 或日志中公开平台凭据、二维码或原始私人消息。

### 企业微信

1. 在「IM 集成」添加「企业微信」连接，使用手机企业微信扫描二维码，在手机上完成创建／授权智能机器人。需要账号具备创建智能机器人的权限。
2. 扫码确认后，机器人凭据自动保存在本机，连接状态在通过平台认证后变为「已连接」。本机最多等待扫码五分钟；等待过期可刷新，关闭弹窗会取消当前扫码等待。
3. 私聊机器人，或将机器人加入企业微信群后 @ 机器人发送消息；收到首条消息后，对应聊天会出现在连接下方。
4. 为这个聊天选择伙伴或团队，确认执行权限与工作范围后授权。每个聊天独立授权；连接成功本身不授予工作执行权限。

已有机器人可以切换为手工填写 Bot ID 和 Secret。在企业微信的智能机器人入口使用「API 模式创建」，选择「使用长连接」，保存机器人后填写凭据；这里使用的是智能机器人 Secret。编辑已有连接时，Secret 留空保留原密钥。

同一机器人只能维持一个有效长连接。若已接入 OpenClaw 或其他客户端，请先停用另一处连接；被替换后 NeuxBot 会停止抢占重连，在关闭其他客户端后保存连接设置即可重新连接。更换为不同机器人时应新建连接并重新授权聊天，避免继承原机器人的执行权限。

本机应用主动连接企业微信，无需公网服务器、回调 URL 或内网穿透。文本、语音转写、图片、文件与图文消息进入已有聊天处理流程，结果及附件通过现有交付记录确认。接收附件目前以安全通用名称保存，不保留原始文件名。平台未返回发送回执时，结果标记为不确定，核对后再重发。关闭窗口后可继续托盘运行；退出应用或设备休眠会中断接收，不承诺恢复未被平台重新推送的离线消息。
