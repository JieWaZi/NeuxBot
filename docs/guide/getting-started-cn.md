# 快速开始

从 [Releases](https://github.com/JieWaZi/NeuxBot/releases) 获取已发布的当前平台安装包。若尚无版本，可按根目录 CONTRIBUTING.md 从源码运行。

1. 安装并启动 NeuxBot。
2. 准备至少一种支持的智能体 CLI，完成对应产品要求的登录或账号配置。
3. 首次引导确认实际安装版本、模型和默认权限。
4. 创建伙伴，可选择本地项目或临时文件夹，输入目标并开始对话。
5. 在工作台查看文件、改动、浏览器与终端；需要分工时创建团队，需要复用步骤时创建工作流。

对话与配置默认保存在本机应用数据目录；智能体与连接器仍可能按所选服务发送数据。选择执行权限前确认获准目录和操作范围。

当前 macOS 安装包仅做临时签名、未经过 Apple 公证，Windows 安装包未做正式代码签名。系统安装提示与下载连接问题的操作见 [README 安装说明](../../README.zh-CN.md)。模型订阅、API 费用及 CLI 安装由对应产品提供。

## 查看版本与升级

1. 打开“设置 → 关于软件”，查看当前版本，点击“检查更新”，也可查看最近成功检查时间。正式安装版本会在启动后自动检查，并在运行期间每 6 小时再次检查；下载由你点击开始。
2. 发现新版本后，查看发行说明，点击“下载新版本”。Shell 原入口位置也会显示下载操作，旁侧保留通知和任务看板入口；下载期间可进入关于软件查看进度，下载完成后仍可检查后续版本。
3. 等待安装包下载并通过完整性校验，再点击“打开安装包”。下载完成只代表安装包已准备好，此时运行的仍是旧版本。
4. 完成正在进行的工作并保存内容，从应用菜单或托盘选择“退出 NeuxBot”。关闭窗口只会隐藏应用，安装前需要真正退出。
5. macOS 打开 DMG，将 NeuxBot 拖到应用程序目录并替换旧版本；Windows 按安装程序提示安装到原安装位置。升级沿用独立用户数据目录，无需删除聊天、伙伴、配置或项目数据。
6. 手动重新启动 NeuxBot，回到“关于软件”核对当前版本。

下载失败可以重试；完整性校验失败的安装包不会被打开。无法打开安装包时可重试，或从“查看发行页面”进入官方 Releases 下载。应用不会主动停止工作、静默覆盖应用或自动重新启动。
