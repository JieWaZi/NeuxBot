## 2. Trigger → Gate → Eval → Ticket / Assignment

1. Source 负责稳定事件身份、actor、human、addressed、Channel 及多 Thread。Intake 规范化有效时间戳、要求至少一 Thread、按 Trigger.id 幂等。scope 不接收的事件保留 filtered disposition；过滤分支不创建 Thread aggregate（Store 的 `trigger_thread` 仍从 Trigger 建索引）。通过的 Trigger 记录 Thread.lastAt 与 correlated，Correlation 不另做 fan-out。多个 Thread 命中同 Ticket 合并为一个 Input，任一自有订阅优先于 context-only。未被 worker 拥有的事件进入第一 Thread 的 pending，活跃订阅的 bot/CI 依然可以同时进 gate（[src/core/intake.ts:19-61](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/core/intake.ts#L19-L61)，[src/app/store.ts:127-132,201-208](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/store.ts#L127-L132)）。
2. 自有 Thread 中人的消息进所有活跃订阅 Ticket，绕过 Gate 的新工作授权。context-only 输入可给活跃 Ticket，但无 followup owner、不得复活 ended Ticket。由 worker 判断是否在既有 Mandate 内，超范围调用 handback；每 Ticket 每 Trigger 一次，直到无 owner 才入 Eval。人的取消订阅保留已接手的消息；面板 re-evaluate 可直接把 owned follow-up 送评估，主 Session 的 requeue 工具会拒绝。未接手且在最后 report/idle 前未读的 follow-up，在 Ticket end/refuse 时释放并可能重新评估；收到现有订阅的人类 follow-up 同时给主 Session 稳定 ID 的 steer relay，目的为模型识别人的 stop（[src/core/model.ts:75-94](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/core/model.ts#L75-L94)，[src/core/part.ts:29-62](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/core/part.ts#L29-L62)，[src/core/tickets.ts:214-269,271-316,338-378](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/core/tickets.ts#L214-L269)，[src/app/runtime.ts:138-153](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/runtime.ts#L138-L153)，[src/app/notices.ts:86-105](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/notices.ts#L86-L105)，[src/app/tools/main.ts:188-200](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/tools/main.ts#L188-L200)）。
3. Gate 优先级（[src/admission.ts:7-13](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/admission.ts#L7-L13)，[src/policy.ts:119-139,167-212](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/policy.ts#L119-L139)）：

|来源/身份|前提与结果|
|---|---|
|名单内 + mention/direct|explicit，所有 mode|
|名单外 + addressed|该 row 默认 ignore，配置允许 explicit/inferred/ignore。explicit cell 先于 Thread followup|
|人的已参与 Thread followup|名单内 explicit，名单外 inferred（需 mode 非 off）；名单外 direct 例外，仅按 table|
|名单内未 addressed|scope 观察全部消息时按 row，默认 inferred，也可 ignore|
|名单外未 addressed|scope 观察全部消息时按 row，默认 ignore，也可 inferred|
|bot 有 actor.id|必须是 Source bot 名单且 addressed 或 observed，仅 inferred|
|无发送者的非人系统事件，如 CI|需 scope 监听且 addressed 或 observed，按 unlistedUnaddressed inferred，mode 非 off|
|其他情况|拒绝并在无 admissible 时记录 ignore 原因|

4. 每 Thread 最多一个持久 active Eval。Passes 先 kick effects，再 `Engine.evaluateDue`，interval 2s，on-demand 并发请求合并为一个后续 pass。Eval 消费 Thread.pending 整批，逐 Trigger gate，选 explicit 高于 inferred，同 strength 取源时间较新或相等时后遇到的一条作为 Eval.primary、Mandate.actor 和 basis。若无 admissible，直接 ignore；已产生 Ticket 的 Trigger 不再借权或产生第二 Ticket。候选卡却用 `candidate.triggers.at(-1)` 作为展示及操作 trigger_id，最强合法 primary 保留在 Eval 和 Ticket 内。卡聚合 handback、batch、至多 8 相关 Ticket（开票优先）、4 个引用 Ticket。卡本身依赖 Feishu sourceLink 查询，有单独短超时与资源回退（[src/app/passes.ts:28-67](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/passes.ts#L28-L67)，[src/core/engine.ts:75-85](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/core/engine.ts#L75-L85)，[src/core/evals.ts:70-119,247-279](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/core/evals.ts#L70-L119)，[src/app/links.ts:20-70](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/links.ts#L20-L70)，[src/app/cards.ts:93-96](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/cards.ts#L93-L96)）。
5. `MasterAssessor.request` 队列 ID = Eval ID，`assessment` 并行最多 4，暂停时 0。构造候选卡后 steer 进**同一个** Main Session，成功返回后 `candidateDelivered`，截止从该时刻而非入队时算，默认 120s（30–600s）。这里的“送达”由 host prompt inbox+flush 返回确定，代码未等模型 read 或首个评估动作。未送达不超时；已送达超时再队列两次，第三次 unavailable；pause 推迟 deadline；政策版本变化记录 unavailable 并重新排队（[src/app/assessment.ts:94-108](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/assessment.ts#L94-L108)，[src/app/delivery.ts:65-84](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/delivery.ts#L65-L84)，[src/core/evals.ts:18-69,217-229,282-288](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/core/evals.ts#L18-L69)，[src/policy.ts:83-87](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/policy.ts#L83-L87)）。
6. 显式请求由主工具 `orchestrator_route` 1–20 items，分别校验/单事务执行 accept、attach、stop、ignore，一个失败不阻挡其他。accept 必须有 title（200 字符内）、英文短 worktree_name（1–4 kebab 词、≤32 字符）、具体 ACK（≤100 词，中文分词）、可选 routing note（≤30 词），explicit scope 直接来自 title。attach 会订阅该 Trigger 的 Thread，在 held Eval 中移除它，其余 batch 重排；不能把 handback 再派原 Ticket，不能 attach 给人停止/无法重验的 ended Ticket，owned follow-up 先由 worker 决定。stop 写 stop Decision、结束 Ticket 为 by=human 并停止 Assignment；gate 非 explicit 或目标不存在/已结束，写带原因的 ignore。Panel 的 stop 直接命令，无 Source Trigger（[src/app/tools/main.ts:17-19,43-152](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/app/tools/main.ts#L17-L19)，[src/core/engine.ts:100-120,155-166](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/core/engine.ts#L100-L120)，[src/core/evals.ts:131-156,211-229,282-315](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/src/core/evals.ts#L131-L156)）。

## 3. Worker → Report → Delivery → Recovery
