# 工作台界面设计核对

本文记录本项目界面职责与验收边界。基础规范见 [UI 标准](../development/ui-cn.md)，资源规范见[资源目录与详情 UI 标准](../development/resource-ui-cn.md)。设计约束不等于真实平台验收结果。

## 1. 工作台框架

模块栏、侧栏、主内容和右侧工作台分别拥有布局区域；共享顶栏高度与语义表面。macOS 窗口按钮由 Electron 管理，Web 不模拟原生控件。窗口布局由 `app/layout` 与共享样式共同维护。

## 2. 导航与操作

伙伴／团队切换历史与浏览器路由历史分别管理。工作看板使用顶栏通知入口，资源库位于伙伴之后，设置位于模块栏底部。详情维护动作归所属分区，不重复进入全局更多菜单。

## 3. Scene 与资源生命周期

布局调整和模块切换保持 Scene、草稿、编辑缓冲、PTY 与原生浏览器身份；真正关闭内容时由原所有者回收。布局组件不接管内容或执行生命周期。

## 4. 页签与焦点

主区与右侧工作台共用页签变体。标题、关闭及新增操作保留明确命中区，键盘焦点使用语义 Token；鼠标点击与拖动不为整块容器增加焦点外框。

## 5. 主题与共享组件

浅暗主题使用相同尺寸与层级。颜色、圆角和排版由共享样式定义，基础控件通过角色变体复用；业务页面不复制控件样式。

## 6. 资源界面的实施差异

目录、详情、添加页按实际角色分别检查：浏览行负责导航，详情行承载真实状态和局部动作，信息字段展示可核实资料，试用仅建立草稿。资源的不可变版本、伙伴安装和账号配置分别维护。

新增共享角色及真实验收结果应以当前实现和定向验证为依据。浅暗主题最终样式、窄容器、长中文、命中区和平台交互仍需实际验收，静态检查与模拟测试不能代替。

## 7. 设置界面

设置分为导航、路径、正文三个区域。共享设置组件维护内容宽度、分组行、字段、危险区与底部保存条。智能体的安装、认证、模型目录分别判定；程序可用不代表登录成功，未知不能展示为零或成功。

安装由 Go Core 管理官方制品下载、校验、完整版本发布和取消。账号使用实际智能体配置的凭据范围；真实授权完成后才报告登录成功。

## 8. 待验证

本次文档与注释清理未打开、控制或截图运行中的页面，也未运行安装、登录或模型调用。此前记录的自动化或平台结果不扩大为本轮验收。后续按明确授权核对浅暗主题、窄容器、键盘及实际平台状态。
