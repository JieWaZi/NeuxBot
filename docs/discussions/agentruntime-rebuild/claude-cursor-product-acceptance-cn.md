# Claude、Cursor 账号与完整聊天链路验收

本轮在已确认的 [隔离重建架构](../../superpowers/specs/2026-11-04-agentruntime-rebuild-design.md) 上接入 Claude 与 Cursor。固定 OpenBot 参考为 `f44dbe116c89a944f8d7d085e092c967b3fce0df`。Go 实现独立迁移其行为与职责，不复制受不同许可约束的 TypeScript 实现。

## 架构与来源

普通聊天使用 `Execution → ThreadLifecycle/Turn → ProviderRuntime → 原生 Client`。账号服务冻结凭据主体、认证代次与模型配置；ProviderRuntime 独占真实进程、租约和资源释放。模型目录复用同一个 ProviderRuntime，不另起探测执行器。ThreadLifecycle 只管理公开聊天绑定、配置兼容和历史交接，Turn 拥有接纳、执行和终态。聊天引用唯一的规范原生终态，用量 SQLite 是可删除重建的查询投影。

| OpenBot 实现依据 | 本轮迁移行为 | Go 落点 |
| --- | --- | --- |
| `agent/provider-runtime.ts`、`provider-drivers.ts` | 账号选择与进程资源生命周期一致；目录与执行使用同一凭据来源 | `internal/agent_next/provider_runtime.go`、`services/aiaccount` |
| `claude-client.ts` 的 `openTurn` | 模型先于依赖的强度；应用失败不发送输入；再验证目标权限 | `session_settings.go`、acp-go Claude owning adapter |
| `acp-client.ts`、`acp-configuration.ts` 与 Cursor flavor | ACP 会话与配置复用；Cursor 原生扩展目录、参数默认值和进程权限由 Cursor adapter 解释 | acp-go `acpclient`、`cursor` |
| `agent/model-catalog.ts`、`agent/session-settings.ts` | 账号目录缓存、模型相关选项、明确默认／关闭／开启、同步设置与异步观察 | `model_catalog.go`、`session_settings.go` |
| `database/conversation-writer.ts`、`database/agent-usage.ts` | 原生终态去重、已知值与缺失区分、按后端与模型分组 | `eventlog_next`、`services/usage` |

原生切换继续保留 NeuxBot 的最近五个完整对话轮次，或旧会话总结后交接。恢复原会话只发送本轮新增内容。没有通过恢复旧 Manager 实现兼容。

## 账号与权限

Claude 支持系统原生登录和受管 API 凭据。系统认证区分原生订阅身份与明确设置的环境／用户设置网关凭据。选中的凭据和端点冻结到租约，模型角色映射单独参与配置兼容。原生 Keychain 使用配置目录的原始拼写，默认目录不被改写成显式覆盖。启动参数不能再次覆盖账号、权限、MCP、插件或工作目录。

Cursor 将登录主体、配置目录和会话数据目录分别处理。状态探测使用原生账号信息，额度读取在同一个令牌上先调用原生 Dashboard `GetMe` 核验主体，再查询额度。订阅额度与原生调用消费不相互替代。

| 产品权限 | Claude | Cursor |
| --- | --- | --- |
| 默认权限 | 原生 `default` 审批模式 | 默认 ACP 进程权限 |
| 自动审批 | 原生模型明确支持时使用 `auto` | 当前原生 ACP 不支持，不展示为可选 |
| 完全访问 | 原生 `bypassPermissions` | 原生 `--force` 对应的进程模式 |

Claude／Cursor 默认权限不宣称具有 Codex 的只读沙箱语义。独立的 `WorkspaceReadOnly` 请求在取得账号租约前拒绝。Claude 模型切换可能自动降级权限，因此模型设置回执中的 mode 与独立通知都纳入有效会话状态；冲突回执不能授权发送。

## 模型、强度与 Fast

目录保留原生模型标识与每模型选项，不用统一的硬编码强度表补齐。Claude 旧版本别名通过控制通道确认；原生目录对不支持的能力省略字段，按已核对的序列化源码解释为不支持。声明支持却缺少可用菜单仍保持未确认，不能直接执行。

Claude 多个角色可以指向同一个具体模型。原生接受 `sonnet` 后仍回读原来的具体模型时，只有关闭额外原生设置来源、冻结宿主凭据环境且角色目标与读回完全一致，才能确认该角色选择。实际模型 ID 与能力仍取具体模型；普通成功 ACK 或显示名称不能代替这种证明。

Claude 默认操作清除已经确认的宿主覆盖，并保留原生配置的实际默认回读。Cursor 参数可能写入原生设置文件，单纯重建进程不能恢复默认，因此从原生每模型目录读取确切默认值，再使用对应的类型化设置请求。缺少默认依据时停止准备，不猜测关闭 Fast 或最低强度。

设置页可以给停用的智能体预配置已确认的默认值；聊天和团队执行另行要求已启用且就绪。手动刷新真正请求 Core 更新目录，未知配置不能保存或发送。

Cursor 的远程模型目录采用 15 秒的独立预算，并受调用方 20 秒总截止时间约束。OpenBot 的 ACP 普通请求默认预算是 30 秒，其 ModelCatalog 对普通后端使用 5 秒并通过会话探测目录；本实现调用 Cursor 的私有原生模型目录接口。真实冷探测约 6–8 秒，因此为这条接口保留专属预算，不套用共享层此前的 3 秒短探测。

## 用量投影

每次规范原生终态只贡献一个调用总计。若终态包含多个模型的主观测，统计投影在同一事务中增加逐模型行；总览、日期、伙伴和后端分组只读取调用行，模型分组只读取相应模型行。同一调用可以参与两个模型分组，不能把模型组调用数相加当成全局调用数。重叠的补充观测不另行记账。

模型分组按原生后端与模型标识区分；系统账号同名不合并后端。费用保留原生上报／估算来源，模型缺失金额不按 Token 比例摊派。Claude 经过原生适配器验证的 `query_pipeline` 仅接受 `claude.result.cost` 来源、USD、估算且为 `turn_delta` 的数值。

旧投影版本从规范终态重建，保留终态原始记录时间，并使旧查询快照失效。分组游标签名绑定筛选和快照，使用快照内行锚点，避免长原生模型标识令服务自身生成的下一页游标超过长度限制。

## 真实产品验收

在隔离 NeuxBot Web、Core 与数据目录中，通过 UI 选择本机 Cursor `2026.10.22-27dcf5f`、Composer 2.5 和默认权限。第一轮要求不使用工具，只输出验收标记；第二轮只要求复述上一轮标记，成功返回相同内容。两条规范终态均为 completed，并属于同一个原生 session。

Cursor 本次没有上报原生 Token 或模型消费明细，SQLite 投影保留两次调用与未知计数。用量页相较原有两次 Codex 验收增加到四次调用，Token 已知小计仍为 50,298，同时显示两次缺少 Token、一次不完整与四次未定价。没有把界面选择的模型或估算 Token 冒充原生消费证据。

Claude 使用本机 `2.1.159`、系统配置中的角色 `sonnet`、原生实际模型 `deepseek-v4-flash`、medium 与默认权限。两轮无工具请求均在 UI 返回相同验收标记；两条 completed 规范终态具有同一原生 session，并归属同一个公开聊天。第一轮为普通输入 23,879、输出 746，第二轮为普通输入 325、缓存读取 23,424、输出 10，合计 48,384 Token。计数取原生 `query_pipeline` 差额，不把助手消息的重复 usage 再次求和。

实机发现的旧版协议差异已作为版本限定行为处理：2.1.159 不上报新版 turn 输入关联字段，适配器只在准确 replay UUID、会话与来源匹配、且没有竞争执行时确认宿主归属。该版本拒绝重叠发送和当前回合插话；不能用未证明的结果填补宿主终态。故障复现期间已有的一轮原生完成记录仍保留为归属未知的消费，没有被删除或伪造关联。

包含此前 Codex 两轮、Cursor 两轮、Claude 成功两轮及上述独立原生完成记录，当前验收数据集共七次消费，页面显示 122,784 已知小计、两次缺少 Token、一次不完整和四次未定价。Claude 原生金额作为服务商估算、已知小计展示，不能视为自定义网关真实账单。该金额没有与模型明细行重复相加。

## 自动化验收与保留边界

具名 Execution 集成测试使用真实 Core、SQLite、ConversationStore、原生 adapter 与协议子进程夹具，覆盖三家后端的两轮增量聊天、取消、Core 重开、原会话恢复及用量查询。Claude 取消轮保留已观察用量，Cursor 未上报 Token 时保留调用数并标记未知。测试覆盖只读拒绝、Claude 权限降档后两次拒绝、Fast 默认恢复与原生回执冲突。

账号隔离、模型目录、原生前缀、前端选择和用量投影分别提交并独立审查。定向包测试、具名竞态测试、前端模块测试和类型检查、生成契约检查用于对应层的证据，不替代真实模型服务或视觉验收。

系统登录的文件或 Keychain 可以被外部程序切换。提交前复核能发现已发生的可观察身份变化；原生协议没有执行进程自身的凭据证明，不能宣称消除了最后的外部切换窗口。

Claude 订阅账号的应用内新增登录流程、独立额度面板、其他 CLI、独立生成入口、acp-go 发布版本固定与候选目录正式替换仍不属于已完成的普通聊天链路。实际服务消费验收单独记录，不能把无 Prompt 初始化或协议夹具描述为在线会话成功。
