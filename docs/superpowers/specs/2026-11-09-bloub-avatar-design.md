# 通用形状头像系统

## 目标与范围

以自维护的 JieWaZi/bloub fork 替换现有专属形象、渲染器及 Avatar Studio。头像由形状、材质、颜色、默认表情组成。保留真实工作状态的视觉反馈，删除聊天输入区悬浮形象及多击召唤，保留侧栏双击资料卡和单击表情互动。

## 来源与边界

Jeremy 的 Bloub 提供框架无关的时间采样、轮廓插值、眼睛和动作核心；OpenBot 所用 NorbertBodziony/bloub fork 提供换色与睡眠／失败辅助动作。记录固定提交和 MIT 许可。自维护 fork 根包 `@neuxbot/bloub` 以 `main` 分支依赖接入，根锁文件固定解析提交，主仓库不保留源码快照；通过公开入口导入框架无关核心、材质和许可。使用这些公开源码，不复制 OpenBot 业务组件。

定制代码使用 React。材质只有毛绒与粒子，默认毛绒。毛绒使用原创生成的完整立体身体，包含凸起前表面、圆润厚度、自身明暗和透明边缘。粒子由形状对应三维体积内的细小光尘投影成完整 SVG 图集，中心饱满，具有左上亮部、右下暗部和疏密变化；不使用光滑外壳上的大圆珠或孔洞纹理。点云由生成命令预先合批，运行时解码为单张纹理，不在逐帧 React 绘图中创建大量粒子节点；细光点使用已有采样时钟，不给眼睛周围额外留白。图集按 4 列 3 行保存，形状及裁格顺序由素材元数据统一拥有。只复用公开几何、换色与动画算法，不包含第三方毛绒图片或原专属身体。

## 数据与组件

既有 avatar 文本字段保存带版本的形状、材质、颜色、表情配置；旧身份仅稳定映射到新配置，不加载旧资源。改名不改变已保存的头像。业务工作状态不持久化进头像配置。

一个 React 头像展示层服务选择器、聊天、列表、欢迎页。静态缩略图使用固定采样，不启动帧循环；动态实例以 30 FPS 更新，空闲从保存的默认表情开始适度轮换，工作中持续切换符合当前活动的表情。工作动作穿插能够完整显示眼睛的姿态，不能只改变被原生动作覆盖的表情配置。身体提供呼吸、搜索倾斜、回答起伏和结束强调，隐藏／离屏暂停，减少动态偏好下仍显示准确状态的固定姿态。

外观和资源作为完整快照交接：切换时保留旧身体与眼睛，只有新纹理换色、解码均完成才提交新材质、颜色、形状与默认表情。首次资源未就绪只保留稳定透明占位，不先绘制平面身体。共享缓存按素材 URL 和颜色保存准备结果，最多保留最近使用的 12 份已解码纹理，不限制在途请求的去重；命中就绪缓存的重挂载同步显示，同材质同颜色的形状和眼睛选择不重复准备。迟到结果不覆盖最新选择；真实加载失败才提交明确降级，完整清理帧循环与监听。

选择器在共享 Popover 中展示材质、形状、眼睛、颜色、随机和重置；触发头像直接反馈当前外观。形状五列、眼睛四列、颜色九列，正常桌面高度保持紧凑，小视口允许滚动。改变单项保留其他项；表单仍沿用现有保存方式。所有选项支持键盘与可访问名称，选中仅通过语义背景和 `aria-pressed` 表达，不叠加勾选图标。不提供动画选择、内部大头像预览或播放暂停控制。静态与动态头像的眼睛统一放大 15%，沿用上游脸部向内增长算法，保持外侧余量、眼间距与眨眼比例。

粒子材质的透明微尘使视觉面积偏小，通过素材元数据 `visualScale=1.2` 单独补偿；毛绒为 1。渲染视域整体放大粒子的身体、眼睛和动作，不改变头像布局槽或资源准备流程。

## 工作状态

| 已有状态   | 新表现                                 |
| ---------- | -------------------------------------- |
| resting    | 兼容旧输入，按空闲呈现                 |
| idle       | 从默认表情开始轮换、眨眼与轻微视线漂移 |
| starting   | 原生睁大眼睛，随后进入思考             |
| thinking   | 思考、轨道与彗星穿插工作表情循环       |
| searching  | 蛋形、六边形与轨道穿插搜索表情循环     |
| working    | 思考、轨道与彗星穿插工作表情循环       |
| connecting | 持续连接环绕线                         |
| responding | 原生播放 → 空闲循环                    |
| waiting    | 原生睁大眼睛 → 警示 → 通知             |
| completed  | 原生感叹 → 通知 → 爆散，6.8 秒后空闲   |
| failed     | 悲伤表情与短暂摇头                     |
| stopped    | 收束为平静表情                         |

单击头像循环不同的友好表情，短暂展示后回到当前状态，点击池覆盖全部 24 种表情并排除当前项；等待、失败和停止优先。侧栏双击或键盘操作打开伙伴资料卡，不召唤聊天浮动角色。工作状态立即打断悬停；结束态不因历史消息重新挂载而重复庆祝。保留现有聊天状态推导入口，头像不新增业务订阅。

除睡眠外的 13 种原生动作仅由真实工作状态编排，不进入外观选择器，不持久化为头像配置。产品取消自动睡眠；旧 sleep 和 resting 输入均按 idle 兼容。形状变化通过完整立体图格的径向 SVG 变形跟随原生轮廓，透明边缘保留，不要求 WebGL。原生 16 表情不变，新增 8 个原创胶囊眼姿态至 24 种，借鉴 dsh-bloub-mood 全池排当前的点击策略。

## 清理与验证

删除旧 vendor/companion、生成脚本、漫游和悬浮展开实现、旧 Studio 及孤立预览入口；删除普通、团队、工作流空白聊天中央的大头像与问候；更新来源声明与相关文档。定向验证配置持久化、全部工作状态、材质与表情组合、快速状态变化、静态模式、生命周期、选择器和移除展开交互。运行受影响前端测试、类型与样式检查，不运行全量检查。用户未授权的真实应用视觉验收不执行。
