# 第三阶段：设置与智能体详情重构

## 目标与范围

按用户本轮指示，第三阶段处理设置；原整体计划中的工作流阶段后移。采用固定 OpenBot v0.62.0 的真实前后端作为结构依据，保留本产品圆角、主题色及现有运行底座。来源和差异见[源码核对](../../discussions/openbot-ui-source-alignment-cn.md#7-设置界面)，布局约束见[UI 标准](../../development/ui-cn.md#设置)。

本轮统一设置左栏与右内容，移除顶级账号入口。智能体列表进入独立详情，详情内管理订阅登录、API 配置、程序安装状态、默认账号、默认模型、推理、Fast 和权限。不建立第二套执行或凭据事实，不保留旧账号页面和旧无归属数据的兼容层。

## 页面与交互

设置只有一个 Scene。分类为通用、智能体、IM 集成、API 集成，平铺显示并由本地搜索过滤，不重复设置或集成分组标题。智能体详情以 `/settings/agents?agent=<runtimeId>` 定位，名称从现有智能体查询读取；顶栏父路径和左上 Back 回列表。切换分类清理所属临时详情，不改变聊天、终端与嵌入浏览器所有权。

列表仅提供默认智能体、已安装搜索和其他可安装项，配置表单不嵌入列表。启用与权限放在详情标题右侧，详情按账号、API、版本与模型分组，删除重复用途区。模型配置保留并排字段，采用白色语义表面和轻边框。账号的创建、重新登录、更换密钥与删除继续调用真实用例；菜单和按钮按当前状态显示。系统账号使用原生 CLI 配置，不复制为受管账号。账号表单保留局部保存，单项默认配置就地提交。删除程序路径、前置参数、配置目录和运行时手工模型的公开字段及持久设置，不建设旧字段兼容。内部原生启动仍使用 Catalog 静态声明和真实检测结果。

用户已明确要求真实安装。未安装版本行右侧提供安装按钮，接入受管下载、校验、发布和实际程序检测；不再把安装指南或复制命令作为安装完成。安装失败保留“官方下载”，通过宿主打开官方页面供手工安装。已安装先检查真实本机与官方版本，确认更高版本才提供更新；重启使用真实原生生命周期。安装、取消、重试和更新由后台拥有生命周期，经现有 runtimes 事件同步，不增加页面轮询。详情中的重新检测仅保留无背景图标，列表检测位于搜索输入框之前。

## 后端与数据职责

受管 AIAccount 增加实际 `runtimeId` 归属，包含 profile 身份；名称在所属智能体内唯一。列表可按归属读取，创建要求明确归属，修改不转移归属。默认账号绑定、模型与推理目录、登录、执行接纳都检查精确归属及协议兼容，协议相同也不允许跨智能体借用账号。

保留现有 `/runtimes` 与 `/ai-accounts` 领域入口，按业务需要精简输入和约束，生成契约通过命令更新。数据库仍由现有注册与 AutoMigrate 管理，无新迁移框架或手工兼容回填。

默认模型优先使用当前账号适用配置：只有选择环境默认账号时才继承环境默认模型和推理；其他账号使用自身默认，再回退原有模型目录规则。删除账号与活跃租约协调，不以 UI 隐藏替代后端校验。

## 分工与验证

主代理负责设置框架、导航和深链、通用／集成表面、规范与集成；三个 GPT-6.1 sol high 子代理分别负责官方安装器、后端账号与安装生命周期、智能体和账号详情；另由用户指定的 GPT-6.1 terra 通过 computer use 核对 OpenBot 的真实界面。文件所有权明确，前后端直接协商同一生成契约。

验证限本轮影响的前端行为测试、类型／格式／UI 策略、Go 包测试及生成契约。真实页面、应用与浏览器不在未经用户授权时打开；静态和自动化结果不作为真实登录、模型、安装或视觉验收。
