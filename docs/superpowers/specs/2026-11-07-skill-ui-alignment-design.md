# 技能列表与详情对齐设计

> 状态：统一资源库、独立添加页及界面调整已实现；添加页完成定向自动化，ZIP 系统文件选择与真实扫描经 Terra 验证，空态及候选截图经 root 验收。新增页头、统一标题及键盘返回经 Terra 固定包复验，root 已查看焦点截图。独立鼠标 hover、跨应用 Finder 拖放、窄窗截断与悬停展开未实测。其他验证范围、发布及授权和数据边界见实施计划。
> 配套：[实施计划](../plans/2026-11-07-skill-ui-alignment.md)、[UI 标准](../../development/ui-cn.md#插件目录与详情)。

## 设计依据

技能页遵守[资源 UI 标准](../../development/resource-ui-cn.md)，复用共享目录、浏览行、详情与添加表单。独立技能、插件技能和内部系统技能的归属分别维护；布局不改变资源所有权。

## 列表映射

使用共享资源页头、整行搜索和相邻添加入口、两列浏览行。条目由图标、名称、说明和尾部真实操作组成；整行详情链接与尾部操作保持独立命中区。技能库仅展示 GitHub 同步和 ZIP 上传的独立技能，不查询或展示插件技能，不展示内部系统技能；不保留旧的“独立安装／来自插件”分组、来源和启停筛选、来源第三行或批量工具栏。

分类由用户自设文本提供，空分类为“未分类”。每个用户分类预览六项，右侧“查看全部”进入真实分类；插件与技能分类页每批 24 项，滚动接近底部时自动读取或追加，不显示“加载更多”按钮；分类页使用面包屑和分类内搜索，不增加返回箭头、重复简介或“精选”，分类状态通过 skillCategory 进入 URL；参数不存在是概览，空字符串是未分类页。详情返回保留该参数，离开技能分类时清理。没有 verified/public 和热度数据，不伪造认证分段、推荐卡或安装量。GitHub 同步与 ZIP 上传共用添加入口，进入独立添加页。资源主列表顶部随当前插件、技能或连接器类型显示对应标题、说明和搜索。

## 添加页映射

添加页保留当前资源 Scene，入口、面包屑末级和可见页标题统一为“添加技能”。页面使用详情同款共享 PageHeader，悬停标题或键盘聚焦时显示共享返回入口，原列表分类、搜索和伙伴上下文经过资源列表范围校验后恢复。页面复用资源表单与宿主底部保存条，使用共享 shell、sm SegmentedControl 按内容自然宽度切换 GitHub／ZIP，不复制 MCP 字段，也不保留旧导入弹窗、安装范围或独立返回按钮。

GitHub 输入与 ZIP 选择均先扫描，再展示真实候选、已存在技能链接与批量选择。ZIP 复用共享 FileDropZone，点击沿用平台选择，拖入浏览器 File 经格式和上传传输上限校验后暂存；原生本地路径不套用浏览器传输上限，解压后的批量预算另行说明。“识别到的技能”区始终显示标题和语义 Card，分别处理未扫描、扫描中、空结果、失败与真实候选。底部保存条在有改动后出现，展示未保存状态、重置和当前阶段主动作。添加调用统一资源库导入；伙伴入口在入库后显式建立当前伙伴安装关系。安装失败保留已入库资源，展示尚未安装的条目与重试，仅重试失败安装，不再次导入或回滚删除。

## 多技能添加为插件

默认仍添加所选独立技能。未入库且勾选至少两个技能时，保存条在主添加动作前提供次级“添加为插件”；点击后在同页填写必填名称与可选说明，展示所选技能，提交动作使用“创建插件”。取消只返回选择步骤，保留来源、扫描批次、勾选及命名草稿；创建失败就近显示准确错误，保留草稿供重试。插件名称使用既有 120 个 Unicode 字符上限，每个插件接受 2–100 个明确选中的候选。

创建通过生成 Client 提交扫描批次与所选候选标识，由 Core 生成 skills-only 插件并返回真实插件和版本身份；不调用独立技能导入，内部技能不重复进入技能库。全局成功后进入插件详情并返回插件库。伙伴入口先创建同一插件，再复用既有插件安装确认，由用户显式安装当前伙伴；安装失败或取消保留已创建插件，重试安装继续操作该插件。包中只包含明确选定的资源并保留来源许可，不加入 MCP、命令或账号，也不提供导出或自动发布的未实现入口。

新增流程的生成 Client 回归覆盖创建、普通失败、取消和既有伙伴安装，前端类型与定向检查通过。本地未安装插件也从浏览条目进入真实详情，尾部安装复用已有身份；目录准备和已安装版本的路由保持各自职责。Terra 固定静态包桌面验收通过，root 已查看选择、命名和安装结果截图：三候选选一时没有插件入口，选二时显示；取消命名保留勾选、名称及说明；创建只含 alpha／beta，不含未选 gamma；从插件库再次进入未安装详情后，显式安装到隔离伙伴 nova。独立技能库搜索 orbit 为零条，总数维持 27，未重复导入独立技能。此次使用隔离数据，未操作外部账号、模型或真实用户资源；不扩大已有鼠标 hover、Finder 拖放及窄窗未实测边界。

## 详情映射

本项目保留已有技能正文、文件及历史能力，对应为身份头、TryCard、真实伙伴安装行、内容区与信息 Card；默认内容为 SKILL.md 单 Card。缺少 examplePrompt/defaultPrompt 时使用产品默认提示“帮我使用这个技能。”，保留同款渐变 TryCard；点击仅准备独立聊天草稿，不自动发送或安装。当前或用户选择的伙伴须已安装、启用且版本与预览一致，才可携带真实 skill／plugin 引用；输入区等真实可用资料到达后一次性插入既有 Mention 节点，不复制 SKILL.md 正文。不可核验的目录预览保留禁用箭头，原因放 title 与可访问描述，不增加卡外常驻说明。身份状态表示真实安装或启停，版本进入信息字段。

独立技能的 SKILL.md／资源文件／版本 Tab 直接复用伙伴／团队同款 SegmentedControl 的 shell、sm、fill 组合，保持胶囊轨道与白色选中面；入口在数据到达前保持可用，URL 和未提交内容随切换保留，同时保留真实文件、历史与版本差异能力；整体仍遵循身份、伙伴、内容、信息顺序；名称与分类合并在身份头的“编辑技能”表单，通过同一次元数据更新保存；分类留空移除，信息 Card 只读展示。全局“删除技能”放身份头，确认删除全部版本与实际安装关系；当前伙伴的启停、更新和管理操作放伙伴安装行。伙伴行的“移除”只断开该伙伴的安装，保留技能、版本及其他伙伴启停；统一资源库不区分公开、私有、所有者或可见范围。详情使用完整实际安装伙伴，列表仍最多预览四个头像，不根据预览补造完整关系、版本或启停。说明与真实分类、来源、版本、更新时间在同一信息 Card，不重复元数据名称、公开私有范围或独立管理／卸载 Card。

插件技能不进入独立技能列表，只从所属插件进入固定版本只读页，呈现身份、TryCard、SKILL.md 和信息，不提供文件、历史、编辑、更新或独立卸载。已安装 URL 固定 pluginId、versionId 和 skillKey；目录预览固定 catalogKey、sourceCommit、archiveSHA256 和 skillKey。普通预览只读取公开资料，不下载归档或触发安装；返回保留并校验实际父入口。

## 功能与边界

保留现有安装、伙伴启停、独立技能编辑及管理行为，不整改 MCP 独立页面。SkillPackage 增加独立于版本的 category 元数据；全局与伙伴列表、详情复用同一字段，现有更新请求接受可选 category，未传不改、空串清空，名称更新保持兼容。GORM AutoMigrate 为已有记录补默认空分类，不建立分类表、第二套状态或 SQL JOIN。产品列表过滤不会删除内部系统任务知识及运行时关系。真实来源在信息区展示，Git 仓库显示 owner/repo，不以托管域名代替作者身份。插件作者 capabilities 不进入用户信息区。旧插件包管理详情以 packageStatus=unsupported 和稳定错误码保留资源、版本与安装事实；身份头提示不可用，提供重新安装说明，保留实际伙伴与卸载／删除，不再展示依赖旧包的组件与执行操作。解析、组件读取和执行继续严格拒绝旧契约。

既有定向自动化与 Terra 桌面验收覆盖统一技能库、原独立添加页、名称与分类同次保存、完整伙伴关系、全局删除确认及暗色真实 Mention。本轮 ZIP 点击系统文件选择与真实扫描出一个候选经 Terra 验证，空态与候选截图经 root 验收；上传上限按“拖放或网页上传的 ZIP”说明并重新生成固定静态包。添加页固定包复验确认唯一可见 h1 和面包屑均为“添加技能”，标题位于自然宽分段上方；键盘聚焦显示共享返回入口，Enter 返回技能列表并保留分类及搜索 `fixture-01`，root 已查看焦点截图。独立鼠标 hover 因 CUA 不支持对应操作而未实测，仅复用现有共享 CSS。跨应用 Finder 拖放因 CUA 无法跨窗口保持拖动而未实测，系统选择成功不替代拖放验收。宽窗口说明无溢出；缩窗操作未成功，真实窄窗截断与悬停展开未实测，class／title 静态实现及定向自动化证据与视觉验收分别记录。

当前正式来源为 Release v0.1.2，三包版本均为 0.1.1，目录与公开资料保持 schemaVersion 1。飞书依赖锁误改上游资产名导致的 404 已修正，依赖准备失败通过白名单稳定错误码分别表达，不概括为三插件账号共同失效。真实生产 HTTP、SQLite 与 CAS 的验证到三包授权挑战和取消为止；固定静态 Renderer 的隔离 Electron 复验中，三包均生成挑战，分别观察 22、21、21 秒后取消。未完成用户供应商登录及真实伙伴安装，前端完成事件后的安装提交仅由 MSW 回归证明。历史发布与验收事实、隔离数据及模型调用边界见[实施计划](../plans/2026-11-07-skill-ui-alignment.md#本轮修正与验收边界)。
