# 插件本地分发设计入口

插件分发与多 CLI 生成、安装和加载统一按[多 CLI 插件生成、分发与加载设计](2026-11-09-multi-cli-plugin-delivery-design.md)实施。

本次按插件整体重构交付新契约，不做历史清单、快照、目录或交付材料兼容与迁移。

分发部分的确定要求为：

- 插件目录和详细资料不通过 `go:embed` 或生成 Go 数据编入 Core。
- 外部轻量索引只包含展示及固定下载所需的信息；详情按需下载并持久缓存。
- Core 启动保留轻索引同步与完整 ZIP 后台预取，索引发布不等待全部详情或归档。
- 下载不创建伙伴安装、不执行包内程序；安装从真实不可变内容生成各 CLI 目标。
- 使用既有受管 `Plugins/` 缓存；原始归档、源内容和派生产物分别校验摘要。

目录、详情、离线、取消和故障边界以主设计为准。此前“内嵌目录与双语详情保证首次离线浏览”的方案不再作为开发依据。
