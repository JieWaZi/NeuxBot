# GitHub 插件增量验收

对应 [GitHub Spec](2026-10-17-github-plugin-design.md) 与 [实现计划](../plans/2026-10-17-github-plugin.md)。范围是已完成插件框架上的 GitHub 提供者及两种授权展示入口。

## 交付内容

- 固定插件源包含飞书办公和 GitHub。GitHub 包直接提供官方远程 MCP，官方 CLI 2.102.0 固定源码的应用隔离构建仅负责 Core 内的共享设备授权；智能体不获得 gh profile 或 CLI 程序目录。
- 共享账号、工作占用、授权等待、取消和 Core 关闭由中立 authorization 组件统一拥有；提供者只适配各自官方协议。同次列表和执行按提供者独立复用状态查询。
- GitHub 原始设备 URL 与一次性验证码分开交付。飞书与 GitHub 均可弹出二维码或点击打开授权网页；关闭弹窗保留等待，验证码可以复制，失败在当前区域反馈。
- 安装、版本更新、显式引用、自动投射和重试复用现有准入。Bearer 只进入精确官方 MCP 的执行连接器，清除冲突认证头和 MCP 选项；白名单允许的 GitHub MCP 可用于受限入口。
- 未提供历史迁移或云端市场。第三方程序原始许可证、固定发布资产和来源摘要随包保留；远程服务部署版本不固定。

## 自动化与本机证据

- 授权适配和执行/API 测试覆盖未登录、提供者实际权限、原始 URL/验证码拆分到达、真实子进程环境隔离、活跃占用、取消后延迟退出、身份变化重试、伪装目的地、冲突请求头和多提供者查询隔离。
- 前端插件测试共 10 项通过，覆盖 QR Dialog、原始链接、关闭后重开、结束关闭、复制验证码及失败反馈，以及原飞书配置与占用流程。
- 固定源检查 4 项通过，离线使用真实 Go 解析器生成两个标准插件包。GitHub CLI 使用固定源码归档、Go 1.27.1 和三处底层钥匙串 service 前缀补丁，六种目标共用相同固定构建输入。上游真实登录编排的内存钥匙串回归在原版源码上复现外部 active slot 被覆盖，隔离补丁后通过；未接触真实钥匙串。Core 拒绝未标识隔离构建版本的程序。
- 公共授权与飞书/GitHub 适配的 `go test -race` 通过。
- 最终 `NODE_OPTIONS=--no-experimental-webstorage pnpm check` 退出 0：前端 254 文件／1601 测试、Electron 71 项，文档、来源、协议生成、类型、Lint、UI/格式、生产构建、启动预算、Go vet 与全部 Go 测试均通过。独立 Review 确认 4 项 Important：钥匙串隔离、真实 Runtime MCP 契约、跳过插件后的占用释放、GitHub 权限包含关系；逐项补失败回归并修复。

## 包体

最终隔离构建的 macOS arm64 应用为 436.6 MiB、Resources 196.3 MiB、DMG 138.5 MiB，构建、签名检查、hdiutil 镜像校验，以及打包 Electron PTY、Core 认证健康检查和停止回收均通过。相对飞书版本的 Resources 158.5 MiB，增量约 37.8 MiB，与随包 GitHub CLI 一致。Resources 上限为 215 MiB；应用 450 MiB、安装包 150 MiB 原上限保留。其他平台仍需各自原生报告。

独立审查固定最终树并复核上述 4 项修复，未发现新增 Critical、Important 或 Minor。真实上游登录隔离回归只使用内存钥匙串；编译结果的来源、补丁、回归与程序摘要已核对。

全量检查曾出现一项既有 `TestAutomaticEntriesExecuteAndDeleteThroughRealCore` 团队续聊时序偶发失败（持久化终态已可读，但进程占用尚未释放）。该测试与本次代码无修改，原样定向复跑 5 次通过；保留此观察；最终原样重跑完整检查已退出 0，不把前次失败写成通过。
