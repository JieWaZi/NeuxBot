# Workflow V2 实施计划

> 根据已确认的 V2 设计实施；使用 subagent-driven-development。用户已批准开发和并行代理，不再增加计划确认环节。

**目标：** 在独立分支交付可运行的 V2 创作、保存、画布、Python、用户决策、伙伴执行和恢复闭环，并启动独立 Web 供验收。

**Spec：** docs/discussions/workflow-v2-design-cn.md、workflow-v2-contracts-cn.md、workflow-v2-acceptance-cn.md。

**全局约束：** 用户最新决定不兼容历史工作流数据，不实现 V1 迁移或双引擎；复用平台 Chat/Execution/Runtime/授权/文件/事件。主代理整体调度，子代理 GPT-6.1 Sol high；共享工作树以文件所有权隔离。先读 AGENTS 路由。只运行受影响定向检查，不运行全量检查。不合并、不推送，保留工作树和 Web 供验收。现有主工作区脏文件不复制。生成文件只通过命令更新。

## Task 1: DSL、脚本与画布编译契约

所有者：dsl 子代理。修改 server/internal/workflow/dsl/**（含生成器源与其生成文件）、server/internal/workflow/function/**。不得修改 services/repositories/API/前端。先测试再实现 V2 sdk、静态 scripts 字节提取、Python 描述与协议、worker 直接 JSON/text 返回语义的编译约束、typed askUser 选项、successCondition、默认结果展示与 CanvasManifest/2；现有耐久解释器可复用。完整静态源码为唯一图源。与 Task 2 协调 exported types/方法；不发明另一套前端类型。SDK 由命令生成。测试覆盖设计示例编译、非法静态导出、动态选项、检查、控制流与重放。

## Task 2: 版本、运行与用户决策服务

所有者：runtime 子代理。修改 server/services/workflow/**、server/apis/workflows/**、server/repositories/*/workflow*。不得修改 internal DSL、agentcapability/agentcli、execution、前端、全局生成文件。实现 source/patch CAS+request 幂等、显式保存产生版本、固定脚本 stdin JSON/protocol、typed question 与稳定候选快照、schema worker 直接返回和有界输出修正、business check、原版本重试/优化证据/恢复。使用已有伙伴，不建立角色层。与 Task1 联络 DSL 接口；与前端代理联络 API 类型。若需要 constants/status_error 由主代理统一处理。定向测试真实 SQLite 和 Python/进程边界。

## Task 3: 画布交互与业务详情

所有者：frontend 子代理。修改 packages/frontend/src/modules/workflow/**，必要的 chat UI 修改先向主代理说明；不得修改生成 API 类型或后端。阅读完整 UI 标准。实现 CanvasManifest/2 消费、输入/步骤/结果与状态叠加、画布侧动态问答（含创作 native question，不在左聊天作答）、默认文本/结构化/文件结果、原版本重试计划和可移除 RunReference 优化入口。保持本产品 UI 风格，共享事件/query，不新增轮询或镜像事实。先与后端协商生成字段。定向组件交互测试及格式检查。

## Task 4: MCP、CLI、执行上下文与 Skill

所有者：主代理。修改 agentcapability、agentcli、services/execution、必要的 runtimes 集成、系统 skills。Operation 为唯一契约；allycli mcp serve --context 固定执行级连接，CLI --context；每轮绑定工作流，来源缺失给可操作诊断；MCP 与 CLI 共用授权/回执；旧 execution/grant 不可继承下一轮权限。系统创作/运行指南精简可靠。定向验证连续回合/旧连接、取消、MCP parity。

## Task 5: 集成、生成与验收

所有者：主代理，完成模块后另派独立审查。统一生成 API/SDK/Skill；按影响运行测试与文档检查，修复接口和行为差异。完成脚本→用户→伙伴→结果与失败恢复的实际链路；真实模型不可用时如实记录，不能以 mock 代替。使用隔离 ALLY_DATA_DIR、独立端口启动 Web，浏览器打开供用户验收。记录实际验收结果，未实测不声称 90%。
