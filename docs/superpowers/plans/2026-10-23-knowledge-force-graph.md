# 知识图谱 Canvas 迁移执行计划

> 执行方式：按用户已确认的 react-force-graph 方案，在当前会话完成；保留当前工作区无关修改，不提交、不推送。

**目标：** 知识图谱改用 `react-force-graph-2d` 的 Canvas、命中检测与 D3 布局，移除自建 SVG Renderer 和逐帧力导向实现。

**架构：** Query Cache 继续拥有 Wiki 关系事实；画布使用独立、按 slug 稳定的可变布局对象，避免引擎改写查询数据。搜索、阅读、筛选及邻域业务保留，WeKnora 的初始分组、主题名称和标签避让继续作为纯几何能力使用。Canvas 绘制缓存轮廓、标签和文本测量，不在平移或普通指针移动时扫描全部节点。

**技术：** React、TypeScript、react-force-graph-2d、Vitest；仅修改图谱和对应依赖、测试、权威文档。

## 约束与重点

- 保留 500 节点概览／邻域与 1500 节点增量预算，不扩大后端或本地分页整改范围。
- 保留节点阅读、双击聚焦、Shift 叠加、悬停展开、拖动固定、分组导航、搜索定位及缩放控件。
- 保留键盘节点选择、展开及视口操作；Canvas 不另造服务器事实。
- 隐藏 Scene、隐藏窗口、零尺寸与卸载均暂停或释放引擎；减少动态效果不执行同步数百步布局。
- 主题色从现有语义 Token 解析，保持图谱延迟加载，不提高启动体积预算。
