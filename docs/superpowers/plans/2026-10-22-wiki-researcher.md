# 知识查询增强与维基研究员实施计划

> 执行方式：在当前工作区按步骤实施，保留已有修改，不提交或推送。

**目标：** 普通伙伴按语境选择知识查询深度；提供名称为 nova、角色为维基研究员的内置伙伴及角色预设。

**架构：** 查询方法统一维护在系统 ally skill 的知识参考中，适配现有 CLI 的页面、原件及分页合同。专用角色复用内置私人助理的 Definition、展示投影和三份 Agent 档案机制，通过既有启动种子幂等创建伙伴。角色描述研究取向，具体查询协议只在公共 skill 维护。

## 范围与约束

- 按用户已给出的两部分范围实现；不增加独立查询引擎或新的授权方式。
- 简单事实、机制分析、深入研究由用户问题与证据缺口决定，用户不必手动选档。
- 只读查询沿当前可见知识库及对话语境选择资料；入库与整理仍须确认唯一目标。
- 识别当前库引用变化、无命中与读取拒绝；不把历史库 ID、概述或空结果当作完整证据。
- 新角色提供身份、风格、方法三份档案，页面展示独立配置核心能力、工作风格和工作方式。
- 复用系统 skill、当前资源授权与前端内置标志，保留已有伙伴资料和档案覆盖。
- 系统技能 Markdown 遵守现有打包器的英文约束，中文展示与工程文档保持中文。
- 维基研究员的三份 Agent 档案沿用私人助理的英文格式：Role / Principles、Working Style、Playbook 的六个编号步骤；展示投影保持中文。

## 重点回归

- 简单定义可在证据足够时结束，详细实现需继续读取关联页面或原件。
- 搜索无命中会换术语或精确标识，不误报知识不存在；权限拒绝不绕过授权。
- 新角色在已有用户伙伴的数据库中补建，重复启动不重复创建。
- 内置伙伴的用户自定义资料及单份档案覆盖在启动后仍然有效。
- 通用伙伴不必切换到专用角色，也能执行机制与深入研究问题。
