# 插件本地分发执行计划入口

此前以 Go 内嵌目录和完整公开资料为前提的执行计划已撤回，不得继续按其完成项或接口实施。

新计划按插件整体重构制定，不增加历史格式、缓存或安装数据迁移的兼容任务。

新的执行计划应从[多 CLI 插件生成、分发与加载设计](../specs/2026-11-09-multi-cli-plugin-delivery-design.md)编写，统一覆盖：

1. 撤除插件数据内嵌与快照生成链路，解耦轻索引、按需详情及启动归档预取。
2. 统一组件解析和各 CLI 声明生成，接入目录准备与现有批量 Skill 封装。
3. 按伙伴准备加载视图与安装关系，打通原生优先和 Skill／MCP 回退。
4. 核对原生适配、授权、并发及退出边界，完成定向测试和真实 CLI 验收。

本文仅防止后续开发继续采用已被用户否定的分发方案，不表示上述工作已经实现。当前状态需重新读取源码和工作树核对。
