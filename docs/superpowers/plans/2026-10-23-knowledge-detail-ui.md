# 知识库详情布局调整实施计划

> **For agentic workers:** 使用 executing-plans 在当前会话逐项实现，最后独立审查。

**Goal:** 移除知识库 Dock，统一知识、摘要、原件导航，并将源文件操作移到正文标题右侧，不增加返回按钮或分隔线。

**Architecture:** 保留当前完整知识库身份、URL 和 Query 数据源。扩展既有目录与阅读器装配，原件采用左侧文件列表并采用服务端分批读取和下滚自动加载；图谱继续按需加载。

**Tech Stack:** React、TypeScript、TanStack Query、现有 shared/ui、Vitest 与 MSW。

**Spec:** 本会话已确认的布局及用户截图。

## 约束与审查重点

- 当前目录有大量未提交修改，以当前文件为基线，不创建干净检出替换它们，不提交或推送。
- 标题区只展示知识库名称与同行靠右的库操作（包含图谱），不展示库简介和独立工具栏；搜索仅保留在左侧。
- 左侧知识、摘要、原件统一切换；原件在左侧仅展示图标与文件名，过长截断，右侧展示所选文件内容；文件夹菜单保持原位。
- 打开源文件在右侧阅读，标题右侧提供下载、重建知识、删除；删除确认与未知结果恢复保持原语义。
- 索引作为知识列表首个文件项；摘要与原件不展示索引；图谱占满标题下全部区域。检查切换后搜索保留、图谱直链、目录读取失败、远端权限及下载错误；不控制运行中的应用。
