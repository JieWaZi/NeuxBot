# 图谱渲染性能优化执行计划

> 执行方式：当前会话内完成；用户已确认直接复用 WeKnora 的机制，除 React 与宿主架构边界外不另造渲染方案。

**目标：** 消除数百节点时每帧 React 整图重渲染，沿用上游交互与性能策略。

**来源：** Tencent/WeKnora `2c0d8384398ca756ee414eef01b71caf91e2caa6` 的 `frontend/src/views/knowledge/wiki/WikiBrowser.vue`；Git blob `5db575db439df4c1622c63f39d3eb71214a7fb79`。

**架构：** React 负责容器、共享按钮与查询事实；独立 SVG Renderer 拥有 DOM、坐标、视口、动画与监听器。服务器数据仍由 TanStack Query 管理。沿用已有布局、语义色、键盘操作与最近节点命中策略。

## 约束与验收

- 保留当前工作区无关修改，不提交、不推送，不打开运行中的页面或应用。
- 布局与视口动画直接更新 SVG 属性；节点和边只在图数据改变时创建。
- 标签与轮廓每 6 个布局帧刷新；轮廓缓存缩放与实际坐标。
- 标签宽度在全部 DOM 写入后集中测量；悬停高亮和拖动不进入 React 状态。
- 拖动只更新当前节点与相连边；增量展开保留旧节点位置、固定状态与视口。
- 概览及邻域沿用上游 500 节点预算，累积展开沿用 1500 节点预算。
- Scene 隐藏、窗口隐藏、卸载后释放或暂停动画、定时器和监听器；恢复保持原坐标。
- 保持键盘、选择、箭头、分组聚焦、搜索定位及真实正文读取。
