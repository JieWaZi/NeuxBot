# 发送链路移除账号状态探测 Implementation Plan

**Goal:** 所有已支持 CLI 的发送、续聊和 steering 不再启动独立账号状态／身份诊断或访问账号状态网络接口；认证失败由真实 CLI 调用返回。

**Architecture:** 账号模块只冻结和租用本地配置、明确选中的托管账号代次及可观察的本地凭据身份。原生 CLI 拥有实际登录和令牌刷新。管理入口的显式登录、检查和额度查询保留原有在线职责，不作为普通执行前置条件。

**Tech Stack:** Go、现有账号与 ProviderRuntime 租约、现有定向 CLI 夹具。

## 约束

- 用户已明确要求直接修复，范围包括十类 CLI，不等待额外方案确认。
- 不用延长超时、探测结果 TTL 缓存或吞掉错误代替移除探测。
- 保留托管账号 ID／代次、配置根、端点、凭据版本和本地账号切换隔离；凭据不进入日志、提示或业务结果。
- 本地身份未知或原生凭据不可由宿主完整观察时，不把未知状态伪造为在线认证成功；由 CLI 实际执行确定登录是否可用。
- 不改飞书等业务插件账号协议，不改 UI，不调用真实模型或控制应用。
- 保留当前共享工作树及并行任务已有改动，不提交混合修改；只运行相关包和回归测试。
