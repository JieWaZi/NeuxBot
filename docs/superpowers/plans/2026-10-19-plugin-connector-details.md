# 插件连接器只读详情修复计划

> 使用 writing-plans 与 test-driven-development，在当前分支保留已有未提交修改并直接实施；不自动提交。

**目标：** 连接器资源列表打开插件 MCP 的只读详情页；插件详情中的 MCP 卡片打开只读弹窗，复用普通连接器的信息布局。

**依据：** 本聊天已确认的页面与 Modal 交互；docs/architecture/plugin-resources-cn.md。

**实现：** 后端读取固定版本保存的组件快照并返回脱敏连接资料及既有智能体兼容规则；目录入口绑定来源摘要。前端从普通连接器详情抽出可复用信息区，同时用于普通详情、插件只读页和弹窗。

## 约束与范围

- 仅查看不执行 MCP、不启动授权程序；启停、编辑和卸载由所属插件负责。
- 不建立独立连接器或复制安装关系；伙伴入口固定其安装版本，版本变化时拒绝旧链接。
- 请求头与环境变量仅展示名称，URL 不含凭据、查询或片段；参数隐藏值。
- 没有真实工具发现结果时显示明确空状态，不伪造测试结果。按用户后续要求补充显式探测，初始化与工具发现仍不调用业务工具。
- 按 AGENTS.md 运行定向验证；不运行全量检查，不操作运行中的 UI。
