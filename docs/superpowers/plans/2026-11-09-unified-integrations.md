# 设置集成入口统一实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将设置侧栏合并为「集成」，正文同时展示 IM、API、MCP 三个竖向分组列表及二级配置。

**Architecture:** 复用现有设置 Scene、智能体列表与详情使用的共享组件。总览按小标题和白色填充分组竖向排列 IM、API、MCP，不使用 Tab。IM 按现有三个平台进入配置；API 与 MCP 分开展示，继续共用已有入站服务、密钥与授权事实。

**Tech Stack:** React、TypeScript、React Router、TanStack Query、共享 UI 和语义 Token。

**Spec:** 用户本次请求及所附智能体列表、详情截图。

## Global Constraints

- 侧栏只保留一个「集成」入口，正文 IM / API / MCP 三块同时显示，不使用 Tab；详情定位进入 URL。
- 面包屑同步真实层级：总览「集成」；详情「集成 / 微信、飞书、企业微信、API 服务或 MCP 服务」，父级可点击返回总览；异步加载时保持挂载。
- IM 列表展示微信、飞书、企业微信三个平台，整行进入平台二级配置，保留现有连接与聊天授权。
- API、MCP 同样在独立竖向分组内采用列表进入二级配置；只展示真实已有条目或服务，不编造三个条目。
- 使用当前智能体设置的语义表面、行密度、48px 身份头、返回操作与分组；不增加重复标题、说明和装饰外框。
- MCP 指本机发布的入站 MCP 服务，保留资源库出站连接器的现有归属。
- 保留已有深链、分页、启停、密钥 CRUD 和错误恢复；不新增业务状态源或改变后端契约。
- 在当前 当前工作分支 分支保留所有无关脏修改；不提交、不推送，不打开或控制运行中 UI。
- 只执行受影响文件、用例、类型、格式和 UI 策略检查，不运行全量检查。

## Review Focus

- 旧 IM connection / binding 深链仍可定位对应配置。
- 旧 API / MCP 设置链接正确定位原配置，不丢失原参数。
- 浏览器后退和详情返回恢复完整三分组总览。
- 加载、读取失败、未知状态不显示虚假连接成功。
- API 与 MCP 共享服务，但只在所属详情编辑，不重复挂载配置。

### Task 1: 统一集成导航、列表和二级配置

**Files:** 设置导航与 Scene、app 设置路由装配、IM 页面、API/MCP 配置组件、相关 i18n 与定向测试；同步 UI 规范中的入口说明。

**Interfaces:** 复用 modules/settings 和 modules/im 公开入口，跨模块装配留在 app；路由参数由统一规则解析。

- [ ] 为唯一侧栏入口、同时显示的三个分组、面包屑层级及父级返回、IM 三项列表与详情返回、API/MCP 列表详情及旧深链写行为测试并确认失败。
- [ ] 实现导航与页面装配，沿用现有 settings 行和详情组件，不修改领域权限与持久化行为。
- [ ] 运行直接受影响的设置、IM、路由与 app-shell 用例；定向格式、lint、类型及 UI 策略检查。
- [ ] 更新权威 UI 规范的设置入口说明；执行文档检查。
- [ ] 自审 diff，提供变更文件清单、测试命令与结果、剩余验收边界；由主代理组织独立审查，不创建提交。

### Task 2: IM 连接三级页面与页内编辑

**Files:** modules/im 的连接行、详情页面与配置表单、BindingForm 宿主适配；app IM 装配与面包屑；相关定向行为测试和当前 UI 规范。

**Interfaces:** 设置仍通过 app 注入公开 IM 页面，详情使用 URL connection/platform/binding；三级页面由同一 useIMConnections/useIMBindings 查询读取权威事实。

**需求补充（优先于 Task 1 的弹窗保留说明）：**

- 平台二级连接列表整行进入三级页面，不再显示眼睛、编辑等成组操作；三级面包屑为「集成 / 平台名称 / 连接名称」，父级平台可点击，详情返回到所属平台。
- 查看连接详情与编辑都在三级页完成，不挂载详情或编辑 Modal；新增连接扫码、专用授权/新对话和删除确认可保留既有 Dialog，并从所属层级操作。
- 三级默认读取真实详情；编辑在同页展开现有配置表单，保存后仍在三级。取消编辑保留已有配置，不返回总览。
- 复用已有连接信息、授权、外部会话记录与配置能力；扫码、手工凭据、验证码、权限、工作范围和联合保存语义不改变。
- 保留最新 revision 读取、空密钥不清已有凭据、keepAwake/enabled 的真实值、BindingForm 的 onBeforeSave 顺序；后台刷新不重置草稿。
- 页面离开或连接切换精确取消尚未完成的登录并释放订阅；读取页面本身不自动开启登录，编辑/连接动作保留现有行为。
- 旧 connection/binding/chat 深链直接到三级；加载/错误/不存在时保持页面壳、面包屑、返回及就近恢复。
- 删除没有真实调用的旧详情 Modal，不仅为旧测试保留死包装；新增连接 Dialog 仍有真实调用，可保留。

- [ ] 提取共用详情正文及无 Modal 的配置表单，保留新增 Dialog，适配绑定表单页内宿主与保存/取消。

- [ ] 定向验证 IM 编辑、扫码取消、联合保存、授权、外部会话、深链/面包屑与设置装配；执行按文件 lint/格式/类型、样式与文档检查，不运行全量。

- 设置白色分组、只读行、编辑字段、空态、状态、危险区与确认必须按真实源码角色和实际宿主级联统一，不能将旧弹窗正文简单移入页面。
