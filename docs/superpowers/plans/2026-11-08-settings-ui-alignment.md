# 设置第三阶段实施计划

依据[设计规格](../specs/2026-11-08-settings-ui-alignment-design.md)执行。

1. 固定 OpenBot 源码版本，核对分类／路径／正文、智能体列表和详情、账号以及安装真实用例。
2. 明确受管账号的实际智能体归属，调整数据库约束、列表和创建契约、默认配置与执行校验；通过生成器更新客户端。
3. 重构设置导航和正文几何，移除独立账号入口；接入智能体详情 URL 与返回，并保持原 Scene 所有权。
4. 按源端分组重构智能体列表和详情，在详情接入订阅、API、程序与模型管理。
5. 同步共享执行选择器的账号归属、切换重置及默认模型／推理行为，更新对应定向测试。
6. 实机核对 OpenBot 已安装／未安装状态与按钮角色；移除多余程序设置，补齐 Claude 订阅登录和受管安装、取消、重试及更新。
7. 完成集成验证和权威文档同步；记录真实平台、视觉、登录与安装验证的剩余边界。
