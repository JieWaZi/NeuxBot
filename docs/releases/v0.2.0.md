# NeuxBot v0.2.0

本版本以 `v0.1.0` 为比较基线，主要新增本机 Web 工作台、统一插件资源库、知识库工作台、企业微信接入、Qoder 智能体与知识 HTTP MCP，并完善执行稳定性、资源导航和构建验证。

## 新增功能

### 本机 Web 工作台

- 新增浏览器入口，与原生应用共享伙伴、聊天、团队、工作流、资源、知识库和自动任务界面。
- 提供独立 Web 启动与打包命令。Web 发布包包含 Core、CLI、前端、Pi Bridge、终端 worker 和 Node 启动器，要求 Node.js 22+；插件包在安装时从独立资源库获取。
- 打开本机网页后，在精确 Host／Origin 校验下自动建立 HttpOnly、SameSite=Strict 会话，无需配对码；写请求继续校验同源与 CSRF，刷新复用有效会话。
- 文件、Git 与交互终端统一由 Core 管理，Web 侧支持上传、下载、工作区访问和终端恢复；退出会话会撤销对应终端所有权。

### 统一插件资源库

- 新增“插件库／我的插件”，统一发现、安装、查看、卸载和更新插件，并为指定伙伴安装固定版本。
- 从自有 HTTP 插件目录读取资源，支持持久缓存和条件请求；安装复验来源、提交与归档摘要，运行时不依赖 Git。
- 插件包含的技能和 MCP 连接器随固定版本一起交付；支持只读详情、来源与许可查看，以及显式连接诊断。
- 伙伴独立启停和卸载插件，共享同一资源的配置与账号；统一更新保留伙伴启停状态，已接纳的工作继续使用冻结的版本与授权快照。
- 飞书与 GitHub 插件通过独立插件包提供专用授权流程；宿主维护共享认证桥接，统一管理授权进度、取消、刷新和权限补充。
- 支持标准插件以及 Codex／Claude 原生交付，提供安装预检、信任确认、身份占用与隔离的供应商依赖。
- 插件业务实现和发布由独立的 neux-plugins 仓库维护；应用保留通用资源、安装和授权桥接能力，安装包不内置供应商 CLI 或插件业务包。

### 知识库工作台

- 新增本地和远端知识库，统一提供资料导入、原件阅读、Wiki 目录、页面正文、摘要、检索和 Canvas 图谱。
- 支持 Wiki 修订、版本历史、差异查看和恢复，保留资料来源、引用与页面之间的关联。
- 新增持久后台整理任务、进度、失败重试与诊断，同库任务按队列串行运行；文档整理使用独立文本生成能力，已有 Wiki 的库内维护使用独立 ACP 会话，页面 AI 修订复用普通聊天。
- 支持为知识库保存执行账号、模型与推理强度，整理时冻结实际配置；默认推理档位按模型真实能力选择最低可用档，而非虚构关闭选项。
- 聊天区分文档整理与已有 Wiki 维护：选定附件先保存为原件，再按库配置生成摘要和知识；Wiki 维护复用手动入口的流程与工具，不重新导入原件。
- 伙伴提交后台任务后，通过事件等待同一任务到终态，再根据保存的报告总结实际修改、合并和遗留问题；单次等待窗口超时不会取消任务。
- Wiki 去重先核实有效内容与来源完整保存到规范页，再归档并永久删除冗余页及其历史，入链改向规范页；原件、规范页、操作回执与整理报告保留。明确要求保留的页面或历史继续保留。
- 维护报告正文随任务持久保存，活动记录与聊天读取同一结果，不依赖维护临时目录中的附件链接；单页修订和既有外部 API Key 不获得重复页永久清理能力。
- 自动任务复用已授权的知识整理入口，普通聊天启动的任务继承当轮实际智能体、账号、模型和推理配置。
- 支持通过 URL、API Key 和指定知识库 ID 挂载远端知识库，并接入已验证的 WeKnora 协议。
- 区分仅保存原件与上传后自动处理两类远端模式；对结果不确定的写入保留原请求身份并对账，避免自动重传造成重复写入。

### 统一 API 发布与知识 MCP

- 新增统一 API 集成设置，为知识库与自动任务分配明确的能力和资源范围；Key 只在创建时显示完整密钥，支持修改授权与立即撤销。
- 知识和自动任务复用同一个发布监听与公开 OpenAPI 合同，管理接口继续使用独立的本机认证。
- 新增 Streamable HTTP MCP 的 `/mcp` 入口，外部 Agent 可以按授权读取、检索、导入、编辑知识及管理整理任务。
- MCP、REST 与 `allycli` 共用知识能力契约；写入通过稳定 `requestId`、版本检查和授权屏障处理幂等、冲突、重试与重启恢复。
- API 服务与 MCP 子开关默认关闭；MCP 依赖 API 服务，两者共享监听、Key 和权限，关闭总服务保留 MCP 开关偏好。

### 企业微信

- 新增企业微信智能机器人连接，支持手机扫码创建／授权机器人，也支持手工配置 Bot ID 和 Secret。
- 通过本机主动长连接接收消息，无需公网回调地址或内网穿透。
- 支持私聊和群聊中的文本、语音转写、图片、文件与图文消息，并通过既有交付流程发送结果及附件。
- 每个外部聊天独立绑定伙伴或团队、执行权限和工作范围；连接成功不会自动授予聊天执行权限。
- 支持扫码刷新与取消、机器人身份隔离、连接被替换后的停止重连，以及发送结果不确定时的明确反馈。

### Qoder 与 Qoder CN

- 在原有智能体之外新增 Qoder 和 Qoder CN 两个独立入口，通过 ACP 复用各自 CLI 登录、模型目录、MCP 和原生会话恢复。
- 支持 PATH 和官方用户级安装位置的探测，多版本选择及明确执行路径；中国版兼容 `qodercn`、`qoder-cn` 和 `qoderclicn`。
- 国际版与中国版分别管理配置，按会话实际声明的权限模式展示选项；续聊重新应用权限选择，并使用官方品牌图标和安装指引。

## 优化与修复

### 使用体验与导航

- CLI 安装探测独立完成；慢探测不再锁住其他智能体的模型配置与保存入口，“重新检测”仅刷新当前选中的 CLI。
- 同一 CLI 的探测串行化，不同 CLI 继续并发，保留实际版本与默认选择的一致性。
- 将 IM 连接管理收拢到设置，使用独立的连接、授权和新建对话弹窗；历史详情保持只读，弹窗关闭后恢复焦点。
- 将工作流列表并入资源库，保留旧 `/workflows` 地址的跳转和搜索条件；新建、查看与删除后返回资源库中的工作流分类。
- 统一资源卡片、语义颜色、工具栏、表单、来源筛选、使用伙伴头像和滚动追加，改善窄内容容器下的布局。
- 知识库目录使用轻量字段和分页读取，正文按需加载；后台刷新保留现有内容，隐藏场景不重复弹出读取错误。
- 修复任务状态读取失败时整理按钮静默禁用的问题；主页面保留错误提示，活动弹窗就地展示错误并支持刷新恢复。
- 修复 Windows 知识库数据库路径被误判为网络路径而导致 Core 启动失败的问题；CI 在 Windows 上直接验证 Core 启动、健康检查和退出。
- 改善账号并发占用、凭据刷新、模型与推理配置校验，以及聊天历史分页和终态消息日志投影。
- 工作区文件监听按真实路径共享，macOS 使用 FSEvents 减少目录监听占用；Git 自动刷新在每次请求完成后至少间隔一秒，同一查询入口处理事件与补读。

### IM、授权与执行稳定性

- 企业微信群消息提交给 CLI 前清理开头的机器人唤起词，不再向执行正文拼接群成员身份；真实 SenderID 继续用于授权和追溯。
- 仅唤起机器人且没有附件时不启动执行，保留正文后续的提及、邮箱及群 `/new` 的真实发送者校验。
- 区分原生工作区与共享插件状态，隔离受管 CLI 路径、凭据目录和账号身份，避免覆盖机器已有的供应商登录状态。
- API 集成禁用或换址时同步关闭旧监听，修复立即重新启用时端口仍被占用的问题。
- 完善知识写入撤权、重试约束、幂等回执和重启恢复，避免通过换 Key 或重试绕过原授权范围。
- 本机 Web 会话过期、Core 重启或注销后释放旧会话资源；WebSocket、CSRF 与终端认证沿同一会话边界验证。

### 启动、构建与工程验证

- 产品与主仓库统一更名为 NeuxBot，更新品牌图、应用字标、包名、Go 模块与仓库链接。
- 提取共享前端和中立平台合同，由 Web／Native 各自负责宿主装配，复用 Core 文件、Git、终端和事件能力。
- 启动错误面板、Mermaid 与重型预览按需加载；统一图谱依赖，保留首屏和工作台启动 JS 体积预算。
- 原生前端资源使用 Brotli 无损压缩交付，恢复后逐项校验原始字节、MIME 与 HTML CSP；启动预算仍统计未压缩产物。
- 保留 macOS arm64、macOS x64 与 Windows x64 原生构建、安装包／应用／资源体积限制、失败体积报告和 SHA256 校验和。
- CI 将生成契约、前端静态检查、前端测试、Web／终端、桌面和 Go 检查并行执行；前端完整测试划分为 4 片，单片失败不取消其他片。
- 同组独立检查在前一项失败后仍继续，只有缺少必要安装或构建产物的后续检查才跳过；最终 `verify` 要求全部任务成功，保留现有测试、超时、格式、类型、生成一致性和体积标准。
- 修复迁移后工作流场景测试的路由、改名后的项目搜索测试词与脚本格式；CI 测试不依赖机器预装 Codex 或本机登录状态。

## 升级与兼容

- 应用标识和默认程序数据目录保留 `com.neuxally.desktop`，受管业务文件根保留 `.neuxally`；本次更名不会移动已有数据库、账号或业务文件。
- `allycli`、`ALLY_*`、既有 `NEUXALLY_*` 插件环境变量、`neuxally-auth/1`、`neuxally-resource://` 和知识集成服务身份保持原技术契约。
- Web 访问仍限本机回环场景，不提供远程多用户登录；同一数据目录只能由一个 Core 持有，Web 与 Native 独立同时运行需要使用不同目录。
- 第三方智能体、插件服务、模型和权限取决于所安装的实际版本及账号；详见随包交付的第三方声明和使用指南。
- 重复页永久清理目前仅用于本地 Wiki 的库内维护；永久删除的冗余页不能从页面历史恢复，未核实的独有内容、版本差异或不完整归并会在报告中保留为待处理问题。
